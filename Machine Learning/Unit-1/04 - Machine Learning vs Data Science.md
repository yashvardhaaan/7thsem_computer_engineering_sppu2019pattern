## Machine Learning

**Machine Learning (ML)** is a branch of Artificial Intelligence that enables computers to **learn patterns from data and make predictions or decisions without being explicitly programmed for every task**.

### Example

A machine learning model can analyze previous house prices and predict the price of a new house.

```text
Previous House Data
        ↓
   ML Algorithm
        ↓
   Trained Model
        ↓
 New House Details
        ↓
 Predicted Price
```

---

## Data Science

**Data Science** is a broader interdisciplinary field that uses **statistics, mathematics, programming, data analysis, visualization, and machine learning** to extract useful information and insights from data.

The main goal of Data Science is to **collect, process, analyze, interpret, and communicate data-driven insights**.

```text
Raw Data
   ↓
Data Collection
   ↓
Data Cleaning
   ↓
Data Analysis
   ↓
Visualization
   ↓
Machine Learning
   ↓
Insights / Predictions
   ↓
Business Decision
```

---

## Machine Learning vs Data Science

| Basis             | Machine Learning                                 | Data Science                                                |
| ----------------- | ------------------------------------------------ | ----------------------------------------------------------- |
| **Meaning**       | Technique for learning patterns from data        | Complete process of extracting knowledge from data          |
| **Scope**         | Narrower                                         | Broader                                                     |
| **Main Goal**     | Prediction and automated decision-making         | Insights, analysis, prediction and decision-making          |
| **Focus**         | Building and improving ML models                 | Managing and analyzing the entire data lifecycle            |
| **Techniques**    | Supervised, unsupervised, reinforcement learning | Statistics, SQL, visualization, ML, data mining, etc.       |
| **Data Cleaning** | Usually required before model training           | Major part of the data science process                      |
| **Visualization** | Not the primary focus                            | Important component                                         |
| **Output**        | Predictions or classifications                   | Insights, reports, visualizations, and predictions          |
| **Example**       | Predicting whether a transaction is fraudulent   | Analyzing customer behavior and predicting future purchases |

## Relationship Between Data Science and Machine Learning

```text
              DATA SCIENCE
        ┌────────────────────────┐
        │ Data Collection        │
        │ Data Cleaning          │
        │ Statistics             │
        │ Data Analysis          │
        │ Visualization          │
        │                        │
        │   ┌───────────────┐    │
        │   │ Machine       │    │
        │   │ Learning      │    │
        │   └───────────────┘    │
        │                        │
        │ Decision Making        │
        └────────────────────────┘
```

### Key Point for Exam

> **Data Science is the broader process of extracting useful knowledge and insights from data, while Machine Learning is a technique used within Data Science to build models that learn from data and make predictions.**

### Simple Example

For an **online shopping company**:

* **Data Science:** Collects customer data, cleans it, analyzes purchasing behavior, creates visualizations, and provides business insights.
* **Machine Learning:** Uses that data to build a model that predicts **which product a customer is likely to purchase next**.

### Conclusion

**Machine Learning and Data Science are closely related but not the same.** Data Science covers the **complete data-to-insight process**, while Machine Learning mainly focuses on **learning patterns from data and making predictions or decisions**.
