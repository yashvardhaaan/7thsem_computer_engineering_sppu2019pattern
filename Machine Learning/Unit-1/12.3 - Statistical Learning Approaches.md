## Definition

**Statistical Learning** is an approach in Machine Learning that uses **statistics, probability, and mathematical methods** to learn relationships and patterns from data.

The main objective is to use available data to **estimate relationships, make predictions, classify observations, and understand uncertainty**.

```text
             Training Data
                  ↓
        ┌──────────────────┐
        │ Statistical      │
        │ Learning Method  │
        └────────┬─────────┘
                 ↓
       Estimate Patterns /
       Relationships
                 ↓
          Statistical Model
                 ↓
          New / Unseen Data
                 ↓
            Prediction
```

---

# Various Statistical Learning Approaches

Statistical learning approaches can broadly be divided into **Supervised Learning** and **Unsupervised Learning**. Statistical methods are also commonly distinguished as **parametric and non-parametric approaches**.

---

## 1. Supervised Statistical Learning

In **supervised statistical learning**, the training data contains both **input variables and a known target/output variable**.

The objective is to learn the relationship between input and output and use it to make predictions.

```text
Input Variables + Target
          ↓
   Statistical Method
          ↓
    Learned Model
          ↓
     New Input
          ↓
      Prediction
```

### Main Types

### a) Regression

Regression is used when the output is **continuous numerical data**.

**Example:** Predicting house prices from area, location, and number of rooms.

A simple linear regression equation is:

**y = β₀ + β₁x + ε**

where:

* `y` = response/output
* `x` = input variable
* `β₀` = intercept
* `β₁` = coefficient
* `ε` = error

### b) Classification

Classification is used when the output belongs to a **category or class**.

**Example:** Predicting whether an email is:

```text
Email → Statistical Model → Spam / Not Spam
```

Common statistical classification methods include **Logistic Regression** and **Linear Discriminant Analysis (LDA)**.

---

# 2. Unsupervised Statistical Learning

In **unsupervised statistical learning**, there is **no predefined target variable**.

The objective is to discover hidden structures, patterns, or relationships in the data.

```text
       Unlabelled Data
              ↓
     Statistical Method
              ↓
     ┌────────┼────────┐
     ↓        ↓        ↓
  Pattern   Groups   Relationships
```

### Example: Clustering

Customer data can be divided into groups based on purchasing behavior.

```text
Customer Data
      ↓
Clustering
      ↓
┌────────┬────────┬────────┐
│ Group 1│ Group 2│ Group 3│
│ Budget │Regular │Premium │
└────────┴────────┴────────┘
```

**K-Means clustering** is a common approach.

---

# 3. Parametric Statistical Approach

In a **parametric approach**, we assume that the data follows a particular mathematical form or probability distribution with a **fixed number of parameters**.

The parameters are estimated from the training data.

### Example

In Linear Regression:

**y = β₀ + β₁x**

The model estimates parameters such as `β₀` and `β₁`.

```text
Data
 ↓
Assume Model Form
 ↓
Estimate Parameters
 ↓
Make Prediction
```

### Examples

* Linear Regression
* Logistic Regression
* Naive Bayes

### Advantages

* Simple
* Fast
* Requires fewer parameters
* Easy to interpret

### Limitation

It may perform poorly if the assumed model does not properly represent the actual data.

---

# 4. Non-Parametric Statistical Approach

A **non-parametric approach** does not assume a fixed mathematical form for the relationship between variables.

It is more flexible and can adapt to complex patterns in the data.

```text
Training Data
      ↓
Flexible Model
      ↓
Learn Data Structure
      ↓
Prediction
```

### Examples

* K-Nearest Neighbors
* Decision Trees
* Kernel methods

### Advantages

* Flexible
* Can model complex relationships
* Makes fewer assumptions about data

### Limitations

* May require more data
* Can require more computation
* Can overfit if not properly controlled

---

# 5. Bayesian Approach

The **Bayesian approach** uses probability to represent uncertainty and updates beliefs when new evidence becomes available.

It is based on **Bayes' theorem**:

**P(A|B) = P(B|A)P(A) / P(B)**

Where:

* `P(A|B)` = posterior probability
* `P(B|A)` = likelihood
* `P(A)` = prior probability
* `P(B)` = evidence

### Example

A medical diagnosis system can calculate the probability that a patient has a disease based on symptoms and test results.

```text
Previous Knowledge
       ↓
    + Evidence
       ↓
 Bayesian Model
       ↓
 Updated Probability
       ↓
    Decision
```

---

# 6. Frequentist Approach

The **Frequentist approach** uses the observed data to estimate unknown parameters and evaluate hypotheses.

It generally focuses on concepts such as:

* Probability based on repeated observations
* Parameter estimation
* Confidence intervals
* Hypothesis testing
* p-values

### Example

A company tests whether a new advertising strategy significantly increases sales.

```text
Sample Data
    ↓
Statistical Test
    ↓
Hypothesis Evaluation
    ↓
Decision
```

# Summary of Statistical Learning Approaches

| Approach           | Main Idea                              | Example            |
| ------------------ | -------------------------------------- | ------------------ |
| **Supervised**     | Learn from input-output pairs          | Regression         |
| **Unsupervised**   | Find hidden patterns                   | Clustering         |
| **Parametric**     | Fixed model form and parameters        | Linear Regression  |
| **Non-Parametric** | Flexible model structure               | KNN                |
| **Bayesian**       | Update probabilities using evidence    | Bayesian Network   |
| **Frequentist**    | Estimate parameters from observed data | Hypothesis Testing |

## Statistical Learning vs Traditional Statistics

Statistical learning and traditional statistical analysis are closely related, but their emphasis can differ.

```text
Traditional Statistics
        ↓
Understand relationships
and uncertainty


Statistical Learning
        ↓
Learn relationships
        ↓
Predict / Classify
        ↓
Generalize to new data
```

Statistical learning places significant emphasis on **prediction and generalization**, while statistical methods also provide tools for **inference and understanding relationships in data**.

## Conclusion

**Statistical Learning Approaches** use statistical and probabilistic techniques to learn patterns from data and make predictions or decisions. Major approaches include **supervised and unsupervised learning, parametric and non-parametric methods, Bayesian methods, and frequentist methods**. These approaches form an important theoretical foundation for Machine Learning and help in **prediction, classification, pattern discovery, parameter estimation, and handling uncertainty**.
