## Introduction

In Machine Learning, **data format** refers to the way data is **organized and represented** so that it can be processed by an ML algorithm.

The format depends on the **number of dimensions (features)** and the type of data being represented.

A common way to represent ML data is using **vectors, matrices, and higher-dimensional tensors**.

---

# 1. Scalar

A **scalar** is a single numerical value.

It has **zero dimensions**.

### Example

```text
x = 25
```

Here, `25` is a scalar value.

### ML Example

The temperature of a particular day:

```text
Temperature = 30°C
```

---

# 2. Vector

A **vector** is a one-dimensional collection of values.

It is commonly used to represent the **features of one data sample**.

### Example

Suppose information about a house contains:

* Area = 1200 sq.ft
* Bedrooms = 3
* Age = 5 years

It can be represented as:

```text
X = [1200, 3, 5]
```

### Diagram

```text
             One Data Sample
                   │
                   ↓
        ┌─────────────────────┐
        │ Area │ Rooms │ Age  │
        │ 1200 │   3   │  5   │
        └─────────────────────┘
                   ↓
             Feature Vector
```

A vector has **one dimension**.

---

# 3. Matrix

A **matrix** is a two-dimensional arrangement of values organized into **rows and columns**.

In Machine Learning, a matrix is commonly used to represent a **dataset**, where:

* Each **row** represents one data sample.
* Each **column** represents one feature.

### Example

```text
             Features
          Area Rooms Age
          ↓     ↓    ↓
        ┌─────────────────┐
House 1 │ 1200   3    5   │
House 2 │ 1500   4    3   │
House 3 │ 1000   2   8   │
        └─────────────────┘
              Matrix X
```

If there are **100 samples and 5 features**, the data matrix has a shape:

```text
100 × 5
```

---

# 4. Higher-Dimensional Data / Tensor

When data has **more than two dimensions**, it can be represented using a **tensor**.

Tensors are especially useful for images, videos, and other complex data.

### Example: Image

A grayscale image can be represented as a **2D matrix**:

```text
      Pixels
   ┌─────────────┐
   │ 0  25  50   │
   │ 10 80  100  │
   │ 20 90  120  │
   └─────────────┘
```

A color image generally has three dimensions:

```text
Height × Width × Channels
```

For example:

```text
224 × 224 × 3
```

where:

* `224` = height
* `224` = width
* `3` = RGB color channels

---

# 5. Multidimensional Data

This is particularly important for the **2025 PYQ**.

When ML data contains multiple dimensions or features, it can be represented using **matrices or tensors** depending on the structure.

### Example: Image Dataset

Suppose we have **10 images**, each of size `224 × 224 × 3`.

The complete dataset can be represented as:

```text
10 × 224 × 224 × 3
```

```text
Number of Images
       │
       ↓
┌──────────────────────────────┐
│ Image 1 → 224 × 224 × 3      │
│ Image 2 → 224 × 224 × 3      │
│ Image 3 → 224 × 224 × 3      │
│ ...                          │
│ Image 10 → 224 × 224 × 3     │
└──────────────────────────────┘
```

This is a **4-dimensional tensor**.

---

# Common ML Data Formats by Dimension

| Dimension    | Format | Example                             | ML Use                                |
| ------------ | ------ | ----------------------------------- | ------------------------------------- |
| **0D**       | Scalar | `25`                                | Single value                          |
| **1D**       | Vector | `[10, 20, 30]`                      | Features of one sample                |
| **2D**       | Matrix | Rows × Columns                      | Tabular datasets                      |
| **3D**       | Tensor | Height × Width × Channels           | Single color image                    |
| **4D**       | Tensor | Samples × Height × Width × Channels | Image datasets                        |
| **Higher-D** | Tensor | Multiple dimensions                 | Video, medical data, complex datasets |

---

# Example: Multidimensional ML Data

Consider a dataset containing **100 color images**, each having:

* Height = 64 pixels
* Width = 64 pixels
* 3 color channels

The data shape is:

```text
100 × 64 × 64 × 3
```

```text
             Dataset
                │
                ↓
       ┌─────────────────┐
       │ 100 Images      │
       └────────┬────────┘
                ↓
       Each Image:
       64 × 64 × 3
                ↓
       4-Dimensional Tensor
```

## Other Important Data Formats

Machine Learning can also process data in different **data forms**, such as:

### 1. Numerical Data

Data represented using numbers.

**Example:**

```text
Age = 21
Salary = ₹50,000
```

### 2. Categorical Data

Data representing categories or labels.

**Example:**

```text
Gender → Male / Female
City → Pune / Mumbai / Delhi
```

### 3. Text Data

Data represented as natural language.

**Example:**

```text
"This product is excellent."
```

It is usually converted into numerical representations before being given to an ML model.

### 4. Image Data

Images are represented as numerical pixel values.

```text
Image → Pixel Values → Matrix/Tensor → ML Model
```

## Conclusion

Machine Learning data can be represented in different formats depending on its dimensionality. **Scalars represent single values, vectors represent one-dimensional features, matrices represent two-dimensional datasets, and tensors represent multidimensional data.** For example, a color image can be represented as a **3D tensor**, while a collection of images can be represented as a **4D tensor**. These formats allow ML algorithms to efficiently process different types of data.
