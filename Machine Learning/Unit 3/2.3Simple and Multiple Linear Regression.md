# **Simple Linear Regression and Multiple Linear Regression**

Both are types of Linear Regression. The main difference is the **number of independent variables used to predict the dependent variable**.

- Simple Linear Regression uses one independent variable.
- Multiple Linear Regression uses two or more independent variables.

We will cover only these two models in this lesson.

## **1. Simple Linear Regression (SLR)**

### **1.1 Definition**

**Exam-ready definition:**

Simple Linear Regression is a supervised machine learning technique used to predict the value of one dependent variable using a single independent variable by establishing a linear relationship between them.

In simple words, it finds a straight-line relationship between one input variable (X) and one output variable (Y).

### **1.2 Example**

Suppose we want to predict a student's marks based on the number of hours studied.

| Study hours (X) | Marks (Y) |
| --------------- | --------- |
| 1               | 30        |
| 2               | 40        |
| 3               | 50        |
| 4               | 60        |
| 5               | 70        |

Here:

- Independent variable (X): Study hours.
- Dependent variable (Y): Marks.
- Number of independent variables: One.

The model learns how marks change with study hours and predicts marks for a new number of study hours.

### **1.3 Mathematical equation**

The equation of Simple Linear Regression is:

\\[ \boxed{\hat{Y}=b_0+b_1X} \\]

Where:

| Symbol       | Meaning                               |
| ------------ | ------------------------------------- |
| \\(\hat Y\\) | Predicted value of dependent variable |
| \\(X\\)      | Independent variable                  |
| \\(b_0\\)    | Y-intercept                           |
| \\(b_1\\)    | Slope or regression coefficient       |

**Meaning of slope (**\\(b_1\\)**):**

It represents the expected change in predicted Y when X increases by one unit.

**Meaning of intercept (**\\(b_0\\)**):**

It represents the predicted value of Y when X is zero.

## **2. Multiple Linear Regression (MLR)**

### **2.1 Definition**

**Exam-ready definition:**

Multiple Linear Regression is a supervised machine learning technique used to predict the value of one dependent variable using two or more independent variables by establishing a linear relationship between them.

In simple words, it predicts one output using multiple input factors.

### **2.2 Example**

Suppose a company wants to predict the price of a house. The price may depend on several factors:

- Area of the house.
- Number of bedrooms.
- Age of the house.
- Distance from the city centre.

Example dataset:

| Area (sq. ft.) | Bedrooms | Age (years) | House price (₹ lakh) |
| -------------- | -------- | ----------- | -------------------- |
| 800            | 2        | 10          | 45                   |
| 1000           | 2        | 5           | 60                   |
| 1200           | 3        | 4           | 75                   |
| 1500           | 3        | 2           | 95                   |
| 1800           | 4        | 1           | 120                  |

Here:

- \\(X_1\\) = Area.
- \\(X_2\\) = Number of bedrooms.
- \\(X_3\\) = Age of house.
- \\(Y\\) = House price.
- Number of independent variables = 3.

The model learns how these input factors relate to house price and predicts the price of a new house.

### **2.3 Mathematical equation**

The general equation of Multiple Linear Regression is:

\\[ \boxed{\hat Y=b_0+b_1X_1+b_2X_2+\cdots+b_nX_n} \\]

Where:

| Symbol                   | Meaning                         |
| ------------------------ | ------------------------------- |
| \\(\hat Y\\)             | Predicted dependent variable    |
| \\(b_0\\)                | Intercept                       |
| \\(b_1,b_2,\ldots,b_n\\) | Regression coefficients         |
| \\(X_1,X_2,\ldots,X_n\\) | Independent variables           |
| \\(n\\)                  | Number of independent variables |

**Understanding the coefficients:**

- \\(b_1\\): Expected change in predicted Y for a one-unit increase in \\(X_1\\), keeping other inputs constant.
- \\(b_2\\): Expected change in predicted Y for a one-unit increase in \\(X_2\\), keeping other inputs constant.
- The same interpretation applies to the other coefficients.

### **2.5 Example of prediction using MLR**

Assume a trained house-price model has the following illustrative equation:

\\[ \hat Y=10+0.05X_1+8X_2-1.5X_3 \\]

Where:

- \\(X_1\\) = Area in square feet.
- \\(X_2\\) = Number of bedrooms.
- \\(X_3\\) = Age in years.
- \\(\hat Y\\) = Predicted price in lakh rupees.

For a house with:

- Area = 1000 sq. ft.
- Bedrooms = 2.
- Age = 5 years.

Substitute the values:

\\[ \hat Y=10+0.05(1000)+8(2)-1.5(5) \\]

\\[ =10+50+16-7.5 \\]

\\[ \boxed{\hat Y=₹68.5\text{ lakh}} \\]

This is an illustrative equation and prediction, not a model trained on the sample table above.

## **3. Difference between Simple and Multiple Linear Regression**

Important for theory questions

| Basis                    | Simple Linear Regression                                   | Multiple Linear Regression                                                               |
| ------------------------ | ---------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Definition               | Predicts output using one independent variable.            | Predicts output using two or more independent variables.                                 |
| Inputs                   | One independent variable.                                  | Two or more independent variables.                                                       |
| Output                   | One dependent variable.                                    | One dependent variable.                                                                  |
| Equation                 | \\(\hat Y=b_0+b_1X\\)                                      | \\(\hat Y=b_0+b_1X_1+\cdots+b_nX_n\\)                                                    |
| Complexity               | Comparatively simple.                                      | More complex.                                                                            |
| Graphical representation | A straight line in 2D.                                     | A plane for two inputs; a hyperplane for more inputs.                                    |
| Example                  | Marks predicted using study hours.                         | House price predicted using area, bedrooms and age.                                      |
| Interpretation           | One coefficient describes the relationship with the input. | Each coefficient describes its input's relationship while keeping other inputs constant. |

## **4. Important points to remember**

1. Both Simple and Multiple Linear Regression are supervised learning techniques.
2. Both predict a continuous numerical dependent variable.
3. Both learn a linear relationship between inputs and output.
4. Simple Linear Regression uses only one independent variable.
5. Multiple Linear Regression uses two or more independent variables.
6. Both can be trained by minimizing the sum of squared residuals.
7. Multiple Linear Regression can suffer from multicollinearity when independent variables are strongly related to each other.

**Important distinction:** Multiple Linear Regression is still called *linear* because the model is linear in its coefficients. It can use several input variables.

# **6. Exam-ready answer (6 marks)**

**Q. Explain Simple Linear Regression and Multiple Linear Regression with suitable examples.**

**Simple Linear Regression:**

Simple Linear Regression is a supervised learning technique used to predict a dependent variable using one independent variable.

Its equation is:

\\[ \hat Y=b_0+b_1X \\]

Example: Predicting student marks using study hours.

**Multiple Linear Regression:**

Multiple Linear Regression is a supervised learning technique used to predict a dependent variable using two or more independent variables.

Its equation is:

\\[ \hat Y=b_0+b_1X_1+b_2X_2+\cdots+b_nX_n \\]

Example: Predicting house prices using area, number of bedrooms and age of the house.

**Difference:**

Simple Linear Regression uses one independent variable, whereas Multiple Linear Regression uses two or more independent variables. Both are used to predict continuous numerical values.

**Conclusion:**

Simple and Multiple Linear Regression are important supervised learning algorithms used for numerical prediction and analysing relationships between variables.
