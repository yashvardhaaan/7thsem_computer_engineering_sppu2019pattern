## **Topic 2.2.9: Gradient Descent**

### **1. What is Gradient Descent?**

**Gradient Descent** is an optimization algorithm used in Machine Learning to minimize the cost (loss) function by repeatedly adjusting the model's parameters.

In Linear Regression, it helps find the optimal values of slope and intercept so that the difference between actual and predicted values becomes as small as possible.

**In simple words:** Gradient Descent repeatedly adjusts the model parameters in the direction that reduces prediction error.

### **2. Why is Gradient Descent used?**

- To minimize the cost function.
- To find optimal model parameters.
- To improve prediction accuracy.
- To train models when direct mathematical solutions are difficult or computationally expensive.

### **3. Cost Function in Gradient Descent**

Before understanding Gradient Descent, we need to understand the **Cost Function**.

A cost function measures how far the model's predictions are from the actual values.

For Linear Regression, the Mean Squared Error cost function is:

\\[ \boxed{J(m,b)=\frac{1}{2n} \sum\_{i=1}^{n}(\hat Y_i-Y_i)^2} \\]

Where:

- \\(J(m,b)\\) = Cost function
- \\(n\\) = Number of training observations
- \\(\hat Y_i\\) = Predicted value
- \\(Y_i\\) = Actual value
- \\(m\\) = Slope
- \\(b\\) = Intercept

The objective is to find values of \\(m\\) and \\(b\\) that minimize the cost function.

**Steps involved:**

1. Initialize the model parameters with initial values.
2. Calculate predicted values.
3. Calculate the cost function.
4. Calculate the gradient (derivative) of the cost function.
5. Update the parameters to reduce the cost.
6. Repeat until the algorithm converges or reaches its stopping condition.

### **5. Mathematical Formula of Gradient Descent**

The general parameter update formula is:

\\[ \boxed{\theta_j= \theta_j-\alpha\frac{\partial J(\theta)} {\partial\theta_j}} \\]

Where:

- \\(\theta_j\\) = Model parameter
- \\(\alpha\\) = Learning rate
- \\(J(\theta)\\) = Cost function
- \\(\frac{\partial J}{\partial\theta_j}\\) = Gradient of cost with respect to the parameter

For Linear Regression:

\\[ \boxed{m=m-\alpha\frac{\partial J}{\partial m}} \\]

\\[ \boxed{b=b-\alpha\frac{\partial J}{\partial b}} \\]

The algorithm updates slope and intercept repeatedly to reduce prediction error.

### **6. What is Learning Rate (α)?**

The **Learning Rate** determines how big a step the algorithm takes while updating the model parameters.

| Learning rate | Effect                               |
| ------------- | ------------------------------------ |
| Very small    | Convergence is slow                  |
| Suitable      | Usually allows stable convergence    |
| Very large    | May overshoot the minimum or diverge |

### **7. Types of Gradient Descent**

There are three commonly discussed types:

1. Batch Gradient Descent
2. Stochastic Gradient Descent (SGD)
3. Mini-Batch Gradient Descent

#### **A. Batch Gradient Descent**

Batch Gradient Descent calculates the gradient using the **entire training dataset** before updating model parameters.

**Working:**

1. Take all training observations.
2. Calculate predictions for all observations.
3. Calculate total cost and gradient.
4. Update parameters once.
5. Repeat for the next iteration.

**Advantages:**

- Stable gradient estimates.
- Smooth convergence for suitable learning rates.
- Uses all observations for each update.

**Disadvantages:**

- Slow for very large datasets.
- Requires more memory.
- Model parameters are updated only after processing the complete dataset.

#### **B. Stochastic Gradient Descent (SGD)**

Stochastic Gradient Descent updates model parameters using **one randomly selected training observation at a time**.

**Working:**

1. Select one training observation.
2. Calculate its prediction error.
3. Calculate the gradient for that observation.
4. Update model parameters immediately.
5. Repeat for other observations.

**Advantages:**

- Faster individual updates.
- Requires less memory.
- Suitable for large datasets and online learning.

**Disadvantages:**

- Updates are noisy.
- Cost may fluctuate instead of decreasing smoothly.
- May require careful learning-rate adjustment.

#### **C. Mini-Batch Gradient Descent**

Mini-Batch Gradient Descent divides the training dataset into small groups called batches.

It updates model parameters after processing each mini-batch.

**Working:**

1. Divide the dataset into mini-batches.
2. Process one mini-batch.
3. Calculate its average gradient.
4. Update parameters.
5. Repeat for the remaining mini-batches.

**Advantages:**

- Faster than full-batch processing in many situations.
- Less noisy than pure SGD.
- Efficient use of modern hardware.

**Disadvantages:**

- Batch size must be selected.
- Requires tuning of hyperparameters.
- Updates are not as smooth as full-batch updates in every case.

### **8. Difference between Batch, Stochastic and Mini-Batch Gradient Descent**

| Feature              | Batch GD              | Stochastic GD                      | Mini-Batch GD                      |
| -------------------- | --------------------- | ---------------------------------- | ---------------------------------- |
| Data used per update | Entire dataset        | One observation                    | Small group                        |
| Update frequency     | Once per full dataset | After every observation            | After every mini-batch             |
| Speed of updates     | Slower                | Fast                               | Fast                               |
| Memory requirement   | High for large data   | Low                                | Moderate                           |
| Gradient stability   | Generally stable      | Noisy                              | Moderately stable                  |
| Suitable for         | Smaller datasets      | Online learning and large datasets | Many practical deep-learning tasks |

**Important for exams:** Batch Gradient Descent uses all observations, SGD uses one observation, and Mini-Batch Gradient Descent uses a small group of observations for each parameter update.

### **9. Advantages and Disadvantages of Gradient Descent**

**Advantages**

1. Simple and widely used optimization algorithm.
2. Can handle large datasets through SGD and mini-batch approaches.
3. Useful for training many Machine Learning models.
4. Iteratively reduces the cost function.
5. Works with complex models where direct solutions may be difficult.

**Disadvantages**

1. Selecting the learning rate can be difficult.
2. May converge slowly.
3. Can get stuck at a local minimum in non-convex problems.
4. Sensitive to feature scaling.
5. May require many iterations to reach convergence.

### **11. Exam-ready conclusion**

Gradient Descent is an optimization algorithm used to minimize the cost function by repeatedly updating model parameters in the direction opposite to the gradient. Its three main types are Batch Gradient Descent, Stochastic Gradient Descent and Mini-Batch Gradient Descent. It is widely used to train Machine Learning models and improve prediction accuracy.
