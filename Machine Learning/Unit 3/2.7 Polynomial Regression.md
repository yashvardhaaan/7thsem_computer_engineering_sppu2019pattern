## **Topic 2.2.7: Ridge Regression**

### **1. What is Ridge Regression?**

**Ridge Regression** is a type of Linear Regression technique that uses **L2 regularization** to reduce overfitting.

In ordinary Linear Regression, the model tries to minimize the sum of squared errors. Sometimes this produces very large coefficient values, especially when input variables are highly correlated.

Ridge Regression adds a penalty term to the loss function to discourage excessively large coefficients.

**In simple words:** Ridge Regression controls the size of model coefficients to make the model less complex and improve its ability to generalize to unseen data.

### **2. Mathematical equation of Ridge Regression**

The Ridge Regression objective function is:

\\[ \boxed{J(\beta)= \sum\_{i=1}^{n}(Y_i-\hat Y_i)^2 +\lambda\sum\_{j=1}^{p}\beta_j^2} \\]

Where:

- \\(Y_i\\) = Actual output
- \\(\hat Y_i\\) = Predicted output
- \\(\beta_j\\) = Model coefficients
- \\(p\\) = Number of input features
- \\(\lambda\\) = Regularization parameter

The first term measures prediction error, while the second term penalizes large coefficients.

**Important:** The intercept is generally not penalized.

### **3. What is L2 Regularization?**

Ridge Regression uses L2 regularization.

\\[ \boxed{L2=\lambda\sum\_{j=1}^{p}\beta_j^2} \\]

It adds the sum of squared coefficient values to the original loss function.

For example, suppose the coefficients are:

\\[ \beta_1=4,\quad \beta_2=3 \\]

Then:

\\[ L2=\lambda(4^2+3^2) \\]

\\[ \boxed{L2=25\lambda} \\]

The model tries to minimize both prediction error and this penalty.

### **4. Working of Ridge Regression**

**Input Training Dataset**

**Apply Linear Regression**

**Add L2 Regularization Penalty**

**Reduce Large Coefficient Values**

**Final Ridge Regression Model**

Steps:

1. Take the training dataset.
2. Apply Linear Regression.
3. Add an L2 penalty to the loss function.
4. Select the regularization parameter \\(\lambda\\).
5. Estimate coefficients by minimizing the penalized loss.
6. Use the resulting model for prediction.

### **5. Role of Lambda (λ)**

Lambda controls the strength of regularization.

| Lambda value      | Effect                                   |
| ----------------- | ---------------------------------------- |
| \\(\lambda=0\\)   | Equivalent to ordinary Linear Regression |
| Small λ           | Small penalty on coefficients            |
| Large λ           | Strong penalty; coefficients shrink more |
| Extremely large λ | May cause underfitting                   |

### **6. Advantages of Ridge Regression**

1. Reduces overfitting.
2. Controls large coefficient values.
3. Handles multicollinearity (high correlation among independent variables).
4. Improves model generalization.
5. Retains all input features in the model.

### **7. Disadvantages of Ridge Regression**

1. Does not usually make coefficients exactly zero.
2. Therefore, it does not perform automatic feature selection.
3. Choosing the correct lambda value can be difficult.
4. Excessive regularization can cause underfitting.
5. Feature scaling is important because the penalty depends on coefficient magnitudes.

### **8. Applications of Ridge Regression**

- House price prediction.
- Stock and financial data modelling.
- Medical data analysis.
- Predicting sales using multiple factors.
- Datasets containing highly correlated features.

### **9. Difference between Linear Regression and Ridge Regression**

| Linear Regression                             | Ridge Regression                          |
| --------------------------------------------- | ----------------------------------------- |
| Minimizes sum of squared errors.              | Minimizes squared errors plus L2 penalty. |
| No regularization.                            | Uses L2 regularization.                   |
| Coefficients can become very large.           | Shrinks coefficient values.               |
| Can overfit in some situations.               | Helps reduce overfitting.                 |
| Does not control coefficient size explicitly. | Controls coefficient size.                |

### **10. Difference between Ridge and Lasso Regression**

| Ridge Regression                       | Lasso Regression                            |
| -------------------------------------- | ------------------------------------------- |
| Uses L2 regularization.                | Uses L1 regularization.                     |
| Penalty is \\(\lambda\sum\beta_j^2\\). | Penalty is \\(\lambda\sum\|\beta_j\|\\).    |
| Shrinks coefficients towards zero.     | Can shrink coefficients exactly to zero.    |
| Generally retains all features.        | Can perform feature selection.              |
| Useful with correlated features.       | Useful when feature selection is desirable. |

### **12. Exam-ready conclusion**

Ridge Regression is a regularized form of Linear Regression that uses L2 regularization to reduce overfitting by penalizing large coefficient values. It minimizes the sum of squared errors along with the squared coefficient penalty. It is especially useful when independent variables are highly correlated. Unlike Lasso Regression, Ridge generally does not eliminate features because its coefficients usually do not become exactly zero.
