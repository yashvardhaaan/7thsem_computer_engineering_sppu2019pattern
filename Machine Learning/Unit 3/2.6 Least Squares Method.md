## **Topic 2.2.5: Least Squares Method**

### **1. What is the Least Squares Method?**

The **Least Squares Method** is a statistical technique used in Linear Regression to find the best-fit regression line by minimizing the sum of the squares of the differences between actual and predicted values.

These differences are called **residuals**.

\\[ \boxed{SSE=\sum(Y_i-\hat Y_i)^2} \\]

The regression line that produces the minimum SSE is selected as the best-fit line.

**In simple words:** It finds the line that gives the smallest total squared prediction error for the given dataset.

### **2. Why is the Least Squares Method used?**

- To find the best-fit regression line.
- To minimize prediction errors.
- To understand the relationship between independent and dependent variables.
- To make predictions using the fitted regression equation.

### **3. Formula of the Least Squares Method**

For a simple linear regression equation:

\\[ Y=aX+b \\]

The slope \\(a\\) and intercept \\(b\\) are calculated using:

**Slope (a):**

\\[ \boxed{a=\frac{n\sum XY-\sum X\sum Y} {n\sum X^2-(\sum X)^2}} \\]

**Intercept (b):**

\\[ \boxed{b=\frac{\sum Y-a\sum X}{n}} \\]

Where:

- \\(n\\) = Number of observations
- \\(\sum X\\) = Sum of X values
- \\(\sum Y\\) = Sum of Y values
- \\(\sum XY\\) = Sum of products of X and Y
- \\(\sum X^2\\) = Sum of squared X values

The final regression equation is:

\\[ \boxed{Y=aX+b} \\]

### **4. Step-by-step procedure**

1. Collect the given X and Y values.
2. Create columns for \\(X\\), \\(Y\\), \\(X^2\\), and \\(XY\\).
3. Calculate the sum of each column.
4. Substitute the values into the slope formula.
5. Calculate the intercept.
6. Form the regression equation.
7. Substitute the required X value to predict Y.

### **5. Solved numerical example – SPPU PYQ**

Actual PYQ · 6 marks

**May/June 2025 – Q2(c)**

Memory capacity and cost of RAM are given below:

| X (Memory in GB) | Y (Cost in $) |
| ---------------- | ------------- |
| 2                | 12            |
| 4                | 16            |
| 8                | 28            |
| 16               | 62            |

Questions:

1. Find the regression line \\(Y=aX+b\\) using the Least Squares Method.
2. Estimate the cost of 32 GB RAM.

May_Jun_2025 (3)(1).pdf

**Step 1: Prepare the calculation table**

| X      | Y       | X²      | XY       |
| ------ | ------- | ------- | -------- |
| 2      | 12      | 4       | 24       |
| 4      | 16      | 16      | 64       |
| 8      | 28      | 64      | 224      |
| 16     | 62      | 256     | 992      |
| **30** | **118** | **340** | **1304** |

Therefore:

\\[ n=4 \\]

\\[ \sum X=30,\quad \sum Y=118 \\]

\\[ \sum X^2=340,\quad \sum XY=1304 \\]

**Step 2: Calculate slope (a)**

\\[ a=\frac{n\sum XY-\sum X\sum Y} {n\sum X^2-(\sum X)^2} \\]

Substitute:

\\[ a=\frac{4(1304)-(30)(118)} {4(340)-(30)^2} \\]

\\[ a=\frac{5216-3540}{1360-900} \\]

\\[ a=\frac{1676}{460} \\]

\\[ \boxed{a=3.6435} \\]

**Step 3: Calculate intercept (b)**

\\[ b=\frac{\sum Y-a\sum X}{n} \\]

\\[ b=\frac{118-(3.6435)(30)}{4} \\]

\\[ \boxed{b=2.1739} \\]

**Step 4: Form the regression equation**

\\[ Y=aX+b \\]

\\[ \boxed{Y=3.6435X+2.1739} \\]

Regression equation obtained

**Step 5: Predict cost for 32 GB RAM**

Given:

\\[ X=32 \\]

Substitute:

\\[ Y=3.6435(32)+2.1739 \\]

\\[ Y=116.592+2.1739 \\]

\\[ \boxed{Y\approx \\$118.77} \\]

**Final answer:** The estimated cost of 32 GB RAM is approximately **$118.77**.

### **7. Advantages and limitations**

**Advantages**

1. Simple and easy to calculate.
2. Provides the best-fit line under the squared-error criterion.
3. Helps estimate unknown values.
4. Uses all the available observations.
5. Provides a mathematical basis for linear regression.

**Limitations**

1. Sensitive to outliers because errors are squared.
2. Assumes a linear relationship for simple linear regression.
3. Predictions outside the observed data range may be unreliable.
4. Results can be affected by unusual or inaccurate observations.

### **8. Difference between Least Squares and Residuals**

| Least Squares Method                             | Residual                                                  |
| ------------------------------------------------ | --------------------------------------------------------- |
| A method for estimating regression coefficients. | Difference between actual and predicted value.            |
| Minimizes the sum of squared residuals.          | Measures an individual prediction error.                  |
| Finds the best-fit regression line.              | Helps evaluate how well the line predicts an observation. |
