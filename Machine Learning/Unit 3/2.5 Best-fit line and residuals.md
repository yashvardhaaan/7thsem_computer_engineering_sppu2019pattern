## **Topic 2.2.4: Best-Fit Line and Residuals**

### **1. What is a Best-Fit Line?**

A **best-fit line** is a straight line that represents the general relationship between independent variable \\(X\\) and dependent variable \\(Y\\).

In Linear Regression, the objective is to find a line that predicts the output as accurately as possible.

The equation is:

\\[ \hat Y=b_0+b_1X \\]

Where:

- \\(\hat Y\\) = Predicted value of Y
- \\(b_0\\) = Y-intercept
- \\(b_1\\) = Slope of the line
- \\(X\\) = Independent variable

**Important:** The best-fit line does not necessarily pass through every data point. It represents the overall trend of the data.

### **2. What are Residuals?**

A **residual** is the difference between the actual observed value and the value predicted by the regression model.

\\[ \boxed{e_i=Y_i-\hat Y_i} \\]

Where:

- \\(e_i\\) = Residual
- \\(Y_i\\) = Actual value
- \\(\hat Y_i\\) = Predicted value

**Example:**

Suppose a model predicts that a student will score 70 marks, but the student actually scores 80 marks.

\\[ e=80-70=10 \\]

Therefore, the residual is +10.

Interpretation:

- Positive residual: Model underpredicts the actual value.
- Negative residual: Model overpredicts the actual value.
- Zero residual: Prediction is exactly correct.

### **4. How is the Best-Fit Line Determined?**

The most commonly used method is the **Ordinary Least Squares (OLS) method**.

OLS finds the regression line by minimizing the sum of squared residuals.

\\[ \boxed{SSE=\sum\_{i=1}^{n}(Y_i-\hat Y_i)^2} \\]

Where:

- SSE = Sum of Squared Errors (or residuals)
- \\(Y_i\\) = Actual value
- \\(\hat Y_i\\) = Predicted value
- \\(n\\) = Number of observations

**Why are residuals squared?**

1. Positive and negative residuals should not cancel each other.
2. Larger errors receive greater penalties.
3. Squared residuals provide a mathematical objective that can be minimized.

The regression line with the minimum SSE is considered the best-fit line under the OLS criterion.

### **5. Solved Example**

Consider the following actual and predicted values:

| X | Actual Y | Predicted Ŷ |
| - | -------- | ----------- |
| 1 | 3        | 4           |
| 2 | 5        | 5           |
| 3 | 8        | 7           |
| 4 | 9        | 8           |

Calculate the residuals and SSE.

**Step 1: Calculate residuals**

\\[ e_i=Y_i-\hat Y_i \\]

| X | Actual Y | Predicted Ŷ | Residual |
| - | -------- | ----------- | -------- |
| 1 | 3        | 4           | -1       |
| 2 | 5        | 5           | 0        |
| 3 | 8        | 7           | +1       |
| 4 | 9        | 8           | +1       |

**Step 2: Square the residuals**

| Residual | Squared residual |
| -------- | ---------------- |
| -1       | 1                |
| 0        | 0                |
| +1       | 1                |
| +1       | 1                |

**Step 3: Calculate SSE**

\\[ SSE=1+0+1+1 \\]

\\[ \boxed{SSE=3} \\]

Therefore, the sum of squared residuals is **3**.

### **6. Important Properties of Residuals**

1. A residual represents prediction error for an individual observation.
2. Positive residual means actual value is greater than predicted value.
3. Negative residual means actual value is less than predicted value.
4. OLS minimizes the sum of squared residuals.
5. For ordinary least squares with an intercept, the sum of residuals is zero (apart from numerical rounding).
6. Residuals help identify unusual observations and assess model fit.

### **7. Difference Between Error and Residual**

| Error                                                             | Residual                                                   |
| ----------------------------------------------------------------- | ---------------------------------------------------------- |
| Difference between actual value and true population relationship. | Difference between actual value and model-predicted value. |
| The true error is generally unknown.                              | Residual can be calculated from observed data.             |
| Related to the underlying population model.                       | Related to the fitted sample model.                        |

**Question: Explain the concept of best-fit line and residuals in Linear Regression.**

A best-fit line is a straight line that represents the relationship between independent and dependent variables. It is used to predict the dependent variable from the independent variable.

The equation of a simple linear regression line is:

\\[ \hat Y=b_0+b_1X \\]

A residual is the difference between the actual observed value and the predicted value.

\\[ e_i=Y_i-\hat Y_i \\]

The Ordinary Least Squares method determines the best-fit line by minimizing the sum of squared residuals.

\\[ SSE=\sum(Y_i-\hat Y_i)^2 \\]

Positive residuals indicate underprediction, while negative residuals indicate overprediction. Residual analysis helps evaluate the accuracy of a regression model.
