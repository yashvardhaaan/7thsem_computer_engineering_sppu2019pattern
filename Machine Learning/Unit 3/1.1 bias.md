## **1.1 What is Bias?**

**Definition (Exam-ready):**

Bias is the difference between the actual values and the average predicted values of a machine learning model. It represents the error introduced by making simplified assumptions in the learning algorithm.

In simple language:

Bias tells us how far a model's predictions are from the actual results because of the assumptions made by the model.

### **1.2 Understand with an example**

Suppose you want to predict the marks of students based on their study hours.

Consider the following actual and predicted marks:

| Student | Actual marks | Predicted marks |
| ------- | ------------ | --------------- |
| A       | 90           | 60              |
| B       | 85           | 58              |
| C       | 80           | 55              |
| D       | 95           | 65              |

Observe that the model consistently predicts marks much lower than the actual marks.

This indicates **high bias** because the model is making predictions that systematically differ from the actual results.

### **1.4 Types of Bias**

For understanding machine learning models, consider these two situations:

**1. High Bias**

- Model makes overly simplified assumptions.
- Model cannot capture complex patterns in the data.
- Training error is generally high.
- Often associated with underfitting.

Example:

Suppose the actual relationship between study hours and marks is curved, but the model assumes that the relationship is a straight line.

The model cannot properly learn the actual pattern.

**2. Low Bias**

- Model makes fewer restrictive assumptions.
- Can capture complex patterns in the dataset.
- Generally has lower systematic prediction error.

However, low bias alone does not guarantee a good model. The model can still suffer from high variance.

### **1.5 Causes of High Bias**

1. Using an overly simple model.
2. Selecting insufficient features.
3. Making incorrect assumptions about the data.
4. Insufficient model complexity.
5. Not learning important patterns from training data.

### **1.6 How to Reduce High Bias**

1. Use a more complex model.
2. Add relevant features.
3. Reduce excessive regularization.
4. Perform feature engineering.
5. Train the model appropriately.

### **1.7 Importance of Bias**

- Helps understand prediction errors.
- Helps identify underfitting.
- Helps select an appropriate model.
- Helps improve model performance.
- Plays an important role in the Bias-Variance Trade-off.
