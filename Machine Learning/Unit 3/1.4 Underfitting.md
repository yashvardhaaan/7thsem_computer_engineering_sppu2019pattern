# **4. UNDERFITTING IN MACHINE LEARNING**

## **4.1 What is Underfitting?**

**Definition (Exam-ready):**

Underfitting is a condition in machine learning in which a model is too simple to learn the underlying patterns and relationships present in the training dataset. As a result, it performs poorly on both training data and unseen testing data.

**In simple language:**

Underfitting occurs when a machine learning model fails to learn properly because it is too simple.

Even after training, the model cannot make accurate predictions.

### **4.2 Understand with a real-life example**

Suppose you want to predict students' examination marks based on their study hours.

Consider the following data:

| Study hours | Actual marks |
| ----------- | ------------ |
| 1           | 20           |
| 2           | 35           |
| 3           | 55           |
| 4           | 70           |
| 5           | 90           |

Imagine that the actual relationship between study hours and marks is nonlinear.

However, you use an extremely simple model that predicts almost the same marks regardless of study hours.

For example:

| Study hours | Actual marks | Predicted marks |
| ----------- | ------------ | --------------- |
| 1           | 20           | 50              |
| 2           | 35           | 50              |
| 3           | 55           | 50              |
| 4           | 70           | 50              |
| 5           | 90           | 50              |

The model fails to capture the relationship between study hours and marks.

This is called **Underfitting**.

## **4.4 Characteristics of Underfitting**

1. The model is too simple.
2. It cannot learn complex patterns from training data.
3. It has high training error.
4. It has high testing error.
5. It is generally associated with high bias.
6. It performs poorly on both training and unseen datasets.

## **4.5 Causes of Underfitting**

There are several reasons why underfitting occurs.

**1. Simple Model Selection**

Using a model that is too simple for the given problem.

Example: Using a straight-line model when the data follows a complex nonlinear relationship.

**2. Insufficient Features**

Not providing enough relevant input features to the model.

**3. Excessive Regularization**

Applying too much regularization can restrict the model from learning important patterns.

**4. Insufficient Training**

Not training the model for an adequate number of iterations.

**5. Poor Feature Engineering**

Failing to create useful features from the available dataset.

**6. Incorrect Model Assumptions**

Choosing a model that does not match the actual relationship in the data.

## **4.6 Effects of Underfitting**

- Low prediction accuracy.
- High training error.
- High testing error.
- Poor learning of data patterns.
- Poor performance on unseen data.
- Inability to capture complex relationships.

## **4.7 How to Reduce Underfitting**

Important for SPPU examination

**1. Increase Model Complexity**

Use a more suitable and powerful model that can learn complex relationships.

Example: Replace an overly simple linear model with polynomial regression when the relationship is curved.

**2. Add More Relevant Features**

Include useful input variables that help the model understand the dataset.

**3. Reduce Regularization**

Decrease excessive regularization so the model can learn important patterns.

**4. Feature Engineering**

Create meaningful features from existing data.

**5. Train for More Iterations**

Allow the model sufficient training time to learn the patterns.

**6. Select an Appropriate Algorithm**

Choose an algorithm suitable for the complexity of the problem.

## **4.8 Training Error and Testing Error in Underfitting**

This is particularly important because SPPU connects underfitting with the Bias-Variance Trade-off.

| Parameter        | Underfitting  |
| ---------------- | ------------- |
| Training error   | High          |
| Testing error    | High          |
| Bias             | High          |
| Variance         | Generally low |
| Model complexity | Too low       |
| Learning         | Insufficient  |

**Why are both errors high?**

The model cannot even learn the training data properly. Therefore, it also performs poorly when new data is provided.

## **4.9 Underfitting vs Overfitting**

Repeated PYQ pattern – 6 marks

| Underfitting                        | Overfitting                                                 |
| ----------------------------------- | ----------------------------------------------------------- |
| Model is too simple.                | Model is unnecessarily complex.                             |
| Cannot learn important patterns.    | Learns training patterns, including noise.                  |
| High bias.                          | High variance.                                              |
| Training error is high.             | Training error is usually low.                              |
| Testing error is high.              | Testing error is usually high.                              |
| Poor performance on training data.  | Good training performance but poor unseen-data performance. |
| Increase suitable model complexity. | Reduce excessive model complexity.                          |
