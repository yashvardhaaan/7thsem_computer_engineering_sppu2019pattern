# **5. OVERFITTING IN MACHINE LEARNING**

## **5.1 What is Overfitting?**

**Definition (Exam-ready):**

Overfitting is a condition in machine learning in which a model learns the training data too closely, including noise and unnecessary patterns. As a result, it performs very well on training data but poorly on new, unseen testing data.

**In simple language:**

Overfitting occurs when a machine learning model memorizes the training data instead of learning general patterns.

It remembers the examples it has already seen but struggles to make accurate predictions on new data.

### **5.2 Understand with a real-life example**

Suppose you are preparing for your Machine Learning examination.

There are two students:

**Student A – Memorization**

- Memorizes all six previous year question papers.
- Remembers exact answers.
- Performs well if the same questions appear.
- Cannot answer unfamiliar questions.

**Student B – Conceptual Learning**

- Understands all the concepts.
- Practises different question patterns.
- Can solve unfamiliar questions.
- Applies knowledge to new problems.

Student A represents overfitting.

Student B represents better generalization.

Similarly, an overfitted machine learning model memorizes training examples rather than learning the actual relationship between input and output.

## **5.4 Characteristics of Overfitting**

1. The model is unnecessarily complex.
2. It learns training data too closely.
3. It memorizes noise and irrelevant patterns.
4. It has very low training error.
5. It generally has high testing error.
6. It is associated with high variance.
7. It performs poorly on unseen data.

## **5.5 Causes of Overfitting**

**1. Excessive Model Complexity**

Using an unnecessarily complex model can cause it to learn noise instead of general patterns.

Example: Using a very high-degree polynomial to fit a small dataset.

**2. Insufficient Training Data**

A model trained on a small dataset may learn patterns that are not representative of the actual population.

**3. Noisy Training Data**

When training data contains errors or random variations, a complex model may learn those variations.

**4. Too Many Features**

Including unnecessary or irrelevant features can increase model complexity.

**5. Excessive Training**

Training a model for too long can cause it to fit training-specific details, particularly in iterative learning algorithms.

**6. Lack of Regularization**

Without appropriate regularization, the model may become unnecessarily complex.

## **5.6 Effects of Overfitting**

- Poor performance on unseen data.
- Low training error but high testing error.
- Unreliable predictions.
- Poor generalization.
- Increased sensitivity to training data.
- Reduced model reliability.

# **5.7 How to Prevent Overfitting**

Very important for SPPU examination

**1. Regularization**

Regularization adds a penalty to the model's objective function to discourage unnecessary complexity.

Two important techniques:

- Lasso Regression (L1 Regularization).
- Ridge Regression (L2 Regularization).

**2. Cross-Validation**

Divide the training dataset into multiple subsets and evaluate the model using different combinations of training and validation data.

This helps identify whether the model performs consistently.

**3. Increase Training Data**

Provide more representative training examples so that the model learns general patterns.

**4. Feature Selection**

Remove irrelevant and unnecessary features to reduce model complexity.

**5. Reduce Model Complexity**

Use an appropriately simple model instead of an unnecessarily complex one.

**6. Early Stopping**

Stop training when validation performance stops improving or starts deteriorating.

**7. Dropout**

In neural networks, dropout randomly disables some neurons during training to reduce dependence on particular neurons and help prevent overfitting.

## **5.8 Training Error and Testing Error in Overfitting**

Consider the following illustrative example:

| Parameter      | Error |
| -------------- | ----- |
| Training error | 2%    |
| Testing error  | 35%   |

The model performs extremely well on training data but poorly on testing data.

This indicates overfitting.

**Why does this happen?**

The model has memorized training examples and their noise instead of learning patterns that apply to new examples.

### **Generalization Gap**

The difference between training error and testing error is called the generalization gap.

\\[ \text{Generalization Gap} = E\_{\text{test}}-E\_{\text{train}} \\]

For the example:

\\[ =35\\%-2\\%=33\\% \\]

Illustrative values, not PYQ numerical data.

A large positive gap can indicate overfitting.

# **5.11 Exam-ready Answer: Overfitting (6 Marks)**

**Q. Explain Overfitting in Machine Learning with suitable example.**

**Definition:**

Overfitting is a condition in machine learning in which a model learns training data too closely, including noise and unnecessary patterns. It performs well on training data but poorly on unseen testing data.

**Characteristics:**

1. Model is unnecessarily complex.
2. Low training error.
3. High testing error.
4. High variance.
5. Poor generalization.

**Causes:**

1. Excessive model complexity.
2. Insufficient training data.
3. Noisy data.
4. Too many irrelevant features.
5. Lack of regularization.

**Techniques to Prevent Overfitting:**

1. Apply Lasso and Ridge regularization.
2. Use cross-validation.
3. Increase training data.
4. Perform feature selection.
5. Reduce model complexity.
6. Apply early stopping and dropout where appropriate.

**Example:**

A model memorizes the examination marks of students in the training dataset. It performs well on those students but makes inaccurate predictions for new students.

This demonstrates overfitting.

**Conclusion:**

Overfitting reduces the generalization ability of a machine learning model. It can be prevented by controlling model complexity, applying regularization and using appropriate validation techniques.
