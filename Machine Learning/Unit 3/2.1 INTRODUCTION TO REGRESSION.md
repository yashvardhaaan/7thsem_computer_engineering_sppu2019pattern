# **1. INTRODUCTION TO REGRESSION**

Subject: Machine Learning · Semester VII · Computer Engineering

Regression is one of the most important concepts in Supervised Learning. It is the foundation for understanding Linear Regression, Least Square Method, Ridge Regression, Lasso Regression and Gradient Descent.

We will first understand the basic concept of Regression. Then we will study its types and related examination questions.

## **1.1 What is Regression?**

**Definition (Exam-ready):**

Regression is a supervised machine learning technique used to predict a continuous numerical value by identifying the relationship between dependent and independent variables using historical data.

**In simple language:**

Regression is used when we want to predict a numerical value.

For example:

- Predicting a student's examination marks.
- Predicting the price of a house.
- Predicting monthly company expenditure.
- Predicting temperature.
- Predicting a person's salary based on experience.

The output of regression is generally a continuous numerical value.

## **1.3 Important Terminology in Regression**

There are two important variables in regression.

### **A. Independent Variable (X)**

**Definition:** An independent variable is the input variable used to predict the output.

It is also called:

- Predictor variable.
- Input variable.
- Explanatory variable.

Example: Number of hours studied.

### **B. Dependent Variable (Y)**

**Definition:** A dependent variable is the output variable whose value is predicted using independent variables.

It is also called:

- Target variable.
- Response variable.
- Output variable.

Example: Examination marks.

### **Example**

| Study hours (X) | Marks (Y) |
| --------------- | --------- |
| 1               | 25        |
| 2               | 40        |
| 3               | 55        |
| 4               | 70        |
| 5               | 85        |

Here:

- X = Study hours (Independent Variable).
- Y = Examination marks (Dependent Variable).

The regression model tries to learn how changes in study hours are associated with changes in marks.

## **1.4 Basic Regression Equation**

The general equation of Simple Linear Regression is:

\\[ \boxed{\hat{Y}=b_0+b_1X} \\]

Where:

| Symbol       | Meaning                         |
| ------------ | ------------------------------- |
| \\(\hat Y\\) | Predicted output                |
| \\(X\\)      | Independent variable            |
| \\(b_0\\)    | Intercept                       |
| \\(b_1\\)    | Regression coefficient or slope |

**Understanding the equation:**

- Intercept (\\(b_0\\)): Predicted value of Y when X is zero.
- Slope (\\(b_1\\)): Change in predicted Y for one-unit increase in X.

# **1.5 Types of Regression Models**

There are several regression models used in machine learning. Each model is suitable for different types of data and relationships.

### **1. Simple Linear Regression**

**Definition:** Simple Linear Regression is a regression technique that predicts a continuous dependent variable using one independent variable.

Example:

Predicting examination marks using study hours.

Equation:

\\[ Y=b_0+b_1X \\]

### **2. Multiple Linear Regression**

**Definition:** Multiple Linear Regression predicts a dependent variable using two or more independent variables.

Example:

Predicting house prices using:

- House area.
- Number of bedrooms.
- Location.
- Age of the house.

Equation:

\\[ Y=b_0+b_1X_1+b_2X_2+\cdots+b_nX_n \\]

### **3. Polynomial Regression**

**Definition:** Polynomial Regression is used when the relationship between independent and dependent variables is nonlinear and can be represented using polynomial terms.

Example: Predicting vehicle speed based on acceleration over time.

Equation:

\\[ Y=b_0+b_1X+b_2X^2+\cdots+b_nX^n \\]

### **4. Ridge Regression**

**Definition:** Ridge Regression is a regularization technique that uses L2 regularization to reduce the magnitude of regression coefficients and control overfitting.

Main feature: It penalizes the square of coefficients.

### **5. Lasso Regression**

**Definition:** Lasso Regression is a regularization technique that uses L1 regularization to reduce coefficients and can eliminate irrelevant features by making some coefficients exactly zero.

Main feature: It performs automatic feature selection.

## **1.6 Comparison of Regression Models**

| Regression model | Number of input variables | Main purpose                     |
| ---------------- | ------------------------- | -------------------------------- |
| Simple Linear    | One                       | Predict linear relationship      |
| Multiple Linear  | Two or more               | Predict using multiple variables |

| Lasso            | One or more               | Feature selection using L1       |

# **1.7 Regression vs Classification**

This is an important supporting concept for understanding supervised learning.

| Regression                                | Classification                                               |
| ----------------------------------------- | ------------------------------------------------------------ |
| Predicts continuous numerical values.     | Predicts discrete classes or categories.                     |
| Output is numerical.                      | Output is categorical.                                       |
| Example: House price prediction.          | Example: Spam or Not Spam.                                   |
| Example: Salary prediction.               | Example: Pass or Fail.                                       |
| MAE, MSE, RMSE and R² are common metrics. | Accuracy, Precision, Recall and F1-score are common metrics. |

# **1.8 Advantages of Regression**

1. Helps predict continuous numerical values.
2. Identifies relationships between variables.
3. Helps in forecasting and decision-making.
4. Can analyse historical data.
5. Supports business planning.
6. Provides interpretable mathematical relationships in many regression models.

# **1.9 Limitations of Regression**

1. Performance depends on data quality.
2. Incorrect model assumptions can reduce accuracy.
3. Outliers can affect some regression models.
4. Simple linear regression cannot capture every nonlinear relationship.
5. Overfitting and underfitting can occur.
6. Correlation does not necessarily imply causation.

# **1.11 Exam-ready Answer – Introduction to Regression [6 Marks]**

**Q. What do you mean by Regression? Explain with a suitable example.**

**Definition:**

Regression is a supervised machine learning technique used to predict continuous numerical values by identifying relationships between dependent and independent variables using historical data.

**Important Components:**

1. Independent Variable (X): Input variable used for prediction.
2. Dependent Variable (Y): Output variable that needs to be predicted.
3. Regression Model: Mathematical relationship between X and Y.
4. Regression Coefficients: Parameters used to determine the relationship.

**Types of Regression:**

1. Simple Linear Regression.
2. Multiple Linear Regression.
3. Polynomial Regression.
4. Ridge Regression.
5. Lasso Regression.

**Example:**

A company collects historical data of monthly expenditure and uses regression to predict its future expenditure.

The model learns the relationship between month and expenditure and predicts expenditure for a future month.

**Applications:**

- House price prediction.
- Salary prediction.
- Sales forecasting.
- Weather forecasting.
- Business expenditure prediction.

**Conclusion:**

Regression is an important supervised learning technique used for numerical prediction and analysing relationships between variables.
