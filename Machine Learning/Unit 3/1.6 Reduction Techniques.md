# **6. TECHNIQUES TO REDUCE UNDERFITTING AND OVERFITTING**

This topic combines the previous two concepts: Underfitting and Overfitting. It is particularly important because SPPU has directly asked about techniques to reduce both problems.

## **6.1 Introduction**

In Machine Learning, a model should learn the important patterns from training data and perform accurately on unseen data.

However, two major problems can occur:

1. **Underfitting:** The model is too simple to learn the actual patterns.
2. **Overfitting:** The model learns training data too closely, including noise and unnecessary patterns.

To solve these problems, we use different techniques to control model complexity and improve generalization.

# **PART A – TECHNIQUES TO REDUCE UNDERFITTING**

## **6.3 What is the objective?**

The objective is to improve the model's ability to learn important patterns from the training dataset.

Underfitting occurs when the model is insufficiently complex or has not learned enough.

We can reduce it using the following techniques.

### **Technique 1. Increase Model Complexity**

**Explanation:**

Use a more powerful model that can learn complex relationships between input and output variables.

Example:

Suppose the relationship between study hours and marks is curved.

A simple linear regression model may fail to represent this relationship.

We can use Polynomial Regression to capture the nonlinear relationship.

**Advantages:**

- Learns complex relationships.
- Can reduce high bias.
- Improves model fitting when the original model is too simple.

### **Technique 2. Add More Relevant Features**

**Explanation:**

Features are input variables used by a machine learning model to make predictions.

Sometimes the model performs poorly because important input features are missing.

Example:

To predict examination marks, consider:

- Study hours.
- Attendance percentage.
- Previous examination marks.
- Practice hours.

Adding relevant features can help the model understand the problem better.

**Advantages:**

- Provides additional information.
- Helps identify important patterns.
- Can improve prediction accuracy.

### **Technique 3. Reduce Regularization**

**Explanation:**

Regularization controls model complexity by adding a penalty to the model's objective function.

However, excessive regularization can make the model too simple and cause underfitting.

Reducing the regularization strength allows the model to learn more complex patterns.

Example:

If Ridge Regression uses an excessively large regularization parameter \\(\lambda\\), coefficients may become too small.

Reducing \\(\lambda\\) can help the model learn better.

### **Technique 4. Feature Engineering**

**Explanation:**

Feature engineering means creating or transforming input variables to help the model learn important patterns.

Example:

Instead of using only study hours, create additional features such as:

- Study hours squared.
- Study hours per week.
- Average daily study hours.

These features may help a model capture relationships that it could not learn using the original inputs.

### **Technique 5. Train for More Iterations**

**Explanation:**

Some machine learning algorithms require repeated training iterations to learn patterns.

If training stops too early, the model may not learn sufficiently.

Allowing additional training iterations can reduce underfitting, provided that training is monitored to avoid overfitting.

### **Technique 6. Select an Appropriate Algorithm**

**Explanation:**

Choose an algorithm according to the complexity and characteristics of the dataset.

Example:

- Linear Regression for approximately linear relationships.
- Polynomial Regression for curved relationships.
- Decision Trees for suitable nonlinear relationships.

The algorithm should match the nature of the problem.

# **PART B – TECHNIQUES TO REDUCE OVERFITTING**

## **6.4 What is the objective?**

The objective is to prevent the model from memorizing training data and help it learn general patterns.

We want the model to perform well on both training data and unseen testing data.

### **Technique 1. Regularization**

Very important

**Definition:**

Regularization is a technique used to prevent overfitting by adding a penalty term to the loss function, discouraging unnecessary model complexity.

There are two important types:

**A. L1 Regularization (Lasso Regression)**

- Adds the absolute values of model coefficients as a penalty.
- Can make some coefficients exactly zero.
- Performs automatic feature selection.
- Helps reduce unnecessary features.

Mathematical representation:

\\[ J(\theta)=MSE+\lambda\sum\_{j=1}^{n}|\theta_j| \\]

**B. L2 Regularization (Ridge Regression)**

- Adds the squared values of model coefficients as a penalty.
- Shrinks coefficients towards zero.
- Generally does not make coefficients exactly zero.
- Helps control model complexity.

Mathematical representation:

\\[ J(\theta)=MSE+\lambda\sum\_{j=1}^{n}\theta_j^2 \\]

Where:

- \\(J(\theta)\\) = Regularized cost function.
- MSE = Mean Squared Error.
- \\(\lambda\\) = Regularization parameter.
- \\(\theta_j\\) = Model coefficient.

**Advantages:**

1. Controls model complexity.
2. Reduces overfitting.
3. Improves generalization.
4. Helps prevent excessive coefficient values.

**Working:**

1. Divide the dataset into K equal-sized folds.
2. Select one fold for validation.
3. Use the remaining K−1 folds for training.
4. Repeat until every fold has been used for validation.
5. Calculate average validation performance.
6. Select an appropriate model and hyperparameters.

**Advantages:**

- Provides a more reliable estimate of model performance.
- Helps identify overfitting.
- Helps select suitable model complexity.
- Makes better use of limited training data.

Note: Cross-validation helps detect and control overfitting; it does not automatically eliminate it.

### **Technique 3. Increase Training Data**

**Explanation:**

Provide more representative training examples to the model.

A larger and more diverse dataset can help the model learn general patterns instead of memorizing a small number of examples.

Example:

Instead of training a handwritten digit recognition model using 100 images, train it using thousands of diverse digit images.

**Advantages:**

- Improves data diversity.
- Helps reduce memorization.
- Can improve generalization.
- Reduces sensitivity to individual training examples.

### **Technique 4. Feature Selection**

**Definition:**

Feature selection is the process of selecting relevant input variables and removing irrelevant or redundant features.

Example:

For predicting house prices, relevant features might include:

- Location.
- Area.
- Number of bedrooms.
- Age of the property.

An irrelevant feature, such as the owner's favourite colour, should generally be excluded.

**Advantages:**

- Reduces model complexity.
- Removes irrelevant information.
- Can reduce overfitting.
- Improves interpretability.

### **Technique 5. Reduce Model Complexity**

**Explanation:**

Use an appropriately simpler model when the current model is unnecessarily complex.

Example:

If a polynomial regression model uses degree 15 to fit a small dataset, reducing its degree may prevent it from fitting random noise.

**Advantages:**

- Reduces unnecessary learning.
- Helps control high variance.
- Improves generalization.

### **Technique 6. Early Stopping**

**Definition:**

Early stopping is a technique in which model training is stopped when performance on validation data stops improving or begins deteriorating.

**Working:**

1. Start training the model.
2. Monitor training and validation errors.
3. Initially, both errors may decrease.
4. When validation error starts increasing, stop training.
5. Retain the model with the best validation performance.

### **Technique 7. Dropout**

**Definition:**

Dropout is a regularization technique used in neural networks in which randomly selected neurons are temporarily deactivated during training.

**Working:**

1. A neural network is created.
2. Some neurons are randomly disabled during a training step.
3. The network learns without depending too heavily on particular neurons.
4. Different neurons are dropped in different training steps.
5. This helps improve generalization.

- Reduces neuron dependency.
- Helps prevent overfitting.

### **Technique 8. Data Augmentation**

**Definition:**

Data augmentation is the process of generating additional training examples by applying transformations to existing data.

Example in image classification:

- Rotation.
- Flipping.
- Cropping.
- Resizing.
- Adjusting brightness.

**Advantages:**

- Increases effective training-data diversity.
- Reduces memorization.
- Improves generalization when transformations preserve the correct labels.

## **6.5 Techniques to Reduce Underfitting vs Overfitting**

| Underfitting                          | Overfitting                                             |
| ------------------------------------- | ------------------------------------------------------- |
| Increase suitable model complexity.   | Reduce excessive model complexity.                      |
| Add relevant features.                | Remove irrelevant features.                             |
| Reduce excessive regularization.      | Apply appropriate regularization.                       |
| Perform feature engineering.          | Perform feature selection.                              |
| Train for sufficient iterations.      | Use early stopping.                                     |
| Choose a more suitable algorithm.     | Use cross-validation to select suitable model settings. |
| Improve the model's ability to learn. | Improve the model's ability to generalize.              |

**Important:** Some techniques can be useful for both problems, but their application differs. For example, feature engineering can help an underfitted model, while feature selection can help an overfitted model.

# **6.9 Exam-ready Answer – Techniques to Reduce Underfitting and Overfitting [6 Marks]**

You can use this answer in your SPPU examination.

**Introduction:**

Underfitting and overfitting are two common problems in machine learning that affect model performance and generalization.

Underfitting occurs when a model is too simple to learn important patterns, whereas overfitting occurs when a model learns training data too closely, including noise.

**A. Techniques to Reduce Underfitting:**

1. Increase model complexity.
2. Add more relevant features.
3. Reduce excessive regularization.
4. Perform feature engineering.
5. Increase training iterations.
6. Select an appropriate algorithm.

**B. Techniques to Reduce Overfitting:**

1. Apply L1 and L2 regularization.
2. Use cross-validation.
3. Increase training data.
4. Perform feature selection.
5. Reduce model complexity.
6. Apply early stopping and dropout where appropriate.

**Conclusion:**

Underfitting and overfitting can be controlled by selecting suitable model complexity, improving training data and applying appropriate regularization techniques. This helps improve model performance and generalization on unseen data.

# **6.10 Quick Revision Notes**

## **Remember the difference**

**To reduce Underfitting**

- Increase model complexity.
- Add relevant features.
- Reduce regularization.
- Perform feature engineering.
- Train sufficiently.

**To reduce Overfitting**

- Apply regularization.
- Increase training data.
- Perform feature selection.
- Use cross-validation.
- Apply early stopping.
- Use dropout for neural networks.

**Golden rule:**

Underfitting → Increase suitable learning capacity.

Overfitting → Control unnecessary model complexity.
