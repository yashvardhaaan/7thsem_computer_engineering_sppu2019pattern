# **2. VARIANCE IN MACHINE LEARNING**

## **2.1 What is Variance?**

**Definition (Exam-ready):**

Variance is the amount by which a machine learning model's predictions change when it is trained on different training datasets.

It measures the sensitivity of a model to changes in the training data.

**In simple language:**

Variance tells us how much a model changes its predictions when we give it different training data.

- High variance: Small changes in training data can cause large changes in predictions.
- Low variance: Predictions remain relatively stable even when training data changes.

## **2.2 Understand Variance with an example**

Suppose we want to predict students' examination marks based on their study hours.

We train three different models using three slightly different training datasets.

| Study hours | Model A | Model B | Model C |
| ----------- | ------- | ------- | ------- |
| 2 hours     | 40      | 65      | 30      |
| 4 hours     | 75      | 45      | 85      |
| 6 hours     | 95      | 90      | 60      |

Notice that the predictions differ considerably between models.

This indicates that the model is sensitive to changes in training data.

This is an example of **High Variance**.

Now consider another situation:

| Study hours | Model A | Model B | Model C |
| ----------- | ------- | ------- | ------- |
| 2 hours     | 40      | 42      | 41      |
| 4 hours     | 65      | 66      | 64      |
| 6 hours     | 90      | 89      | 91      |

Here, predictions are almost similar across all three models.

This indicates **Low Variance**.

In machine learning, we can represent prediction variance at a particular input \\(x\\) as:

\\[ \operatorname{Var}(f(x)) = E[(f_D(x)-E[f_D(x)])^2] \\]

Where:

- \\(f_D(x)\\) = Prediction from a model trained on dataset D.
- \\(E[f_D(x)]\\) = Average prediction across different training datasets.
- \\(E\\) = Expected value.

**Interpretation:** The greater the spread of predictions across different training datasets, the higher the variance.

## **2.4 Types of Variance**

### **1. High Variance**

High variance

Characteristics:

1. Model is highly sensitive to training data.
2. Small changes in training data produce different predictions.
3. Model may learn noise and unnecessary patterns.
4. Training error is usually low.
5. Testing error is usually high.
6. It is commonly associated with overfitting.

**Example:**

Suppose a model memorizes the marks of every student in its training dataset instead of learning the general relationship between study hours and marks.

When new students are given as input, the model performs poorly.

This is high variance.

### **2. Low Variance**

Low variance

Characteristics:

1. Model predictions are relatively stable.
2. Small changes in training data have little effect.
3. Model learns relatively consistent patterns.
4. It is generally less sensitive to noise.
5. It can generalize better when bias is also sufficiently low.

**Example:**

A model learns the general relationship between study hours and examination marks.

Even if a few training examples change, its predictions remain almost the same.

This is low variance.

## **2.6 Causes of High Variance**

1. Using an excessively complex model.
2. Having insufficient training data.
3. Training on noisy data.
4. Using too many irrelevant features.
5. Overfitting the training dataset.
6. Using a model that is highly sensitive to small data changes.

## **2.7 How to Reduce Variance**

These techniques help improve model stability:

**1. Increase Training Data**

More representative training data can help the model learn general patterns instead of memorizing individual examples.

**2. Regularization**

Techniques such as Lasso and Ridge Regression penalize excessive model complexity.

**3. Feature Selection**

Remove irrelevant or unnecessary features to reduce model complexity.

**4. Cross-Validation**

Use different subsets of data to evaluate model stability.

**5. Reduce Model Complexity**

Use a simpler model when the current model is unnecessarily complex.

**6. Ensemble Learning**

Methods such as Bagging and Random Forest can reduce prediction variance by combining multiple models.

## **2.8 Difference between High Variance and Low Variance**

| High Variance                                      | Low Variance                                                    |
| -------------------------------------------------- | --------------------------------------------------------------- |
| Highly sensitive to training data.                 | Less sensitive to training data.                                |
| Predictions change significantly.                  | Predictions remain relatively stable.                           |
| Often associated with overfitting.                 | Often associated with simpler, more stable models.              |
| Training error is usually low.                     | Training error may be higher.                                   |
| Testing error is often high.                       | Testing performance can be more consistent.                     |
| Can be reduced using regularization and more data. | Can be achieved through suitable model complexity and training. |
