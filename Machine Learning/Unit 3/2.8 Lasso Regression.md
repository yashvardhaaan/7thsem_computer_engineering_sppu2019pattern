## **Topic 2.2.8: Lasso Regression**

### **1. What is Lasso Regression?**

**Lasso Regression** (Least Absolute Shrinkage and Selection Operator) is a regularized form of Linear Regression that uses **L1 regularization** to reduce overfitting and perform feature selection.

It adds a penalty based on the absolute values of model coefficients to the ordinary regression loss.

**In simple words:** Lasso Regression reduces the size of less useful coefficients and can make some coefficients exactly zero. This allows it to remove less important features automatically.

### **2. Mathematical equation of Lasso Regression**

The objective function of Lasso Regression is:

\\[ \boxed{J(\beta)= \sum\_{i=1}^{n}(Y_i-\hat Y_i)^2+ \lambda\sum\_{j=1}^{p}|\beta_j|} \\]

Where:

- \\(Y_i\\) = Actual output
- \\(\hat Y_i\\) = Predicted output
- \\(\beta_j\\) = Model coefficients
- \\(p\\) = Number of input features
- \\(\lambda\\) = Regularization parameter

The first term represents prediction error, while the second term is the L1 penalty.

**L1 regularization:**

\\[ \boxed{L1=\lambda\sum\_{j=1}^{p}|\beta_j|} \\]

Unlike Ridge Regression, Lasso uses the absolute values of coefficients rather than their squares.

### **3. How does Lasso Regression work?**

**Input Dataset**

**Apply Linear Regression**

**Add L1 Regularization Penalty**

**Shrink Less Useful Coefficients**

**Some Coefficients Become Zero**

**Final Model with Selected Features**

Steps:

1. Take the training dataset.
2. Apply Linear Regression.
3. Add an L1 penalty to the loss function.
4. Select the regularization parameter \\(\lambda\\).
5. Minimize the penalized loss function.
6. Less useful feature coefficients may become exactly zero.
7. Use the remaining features to make predictions.

### **4. Feature Selection using Lasso Regression**

Feature selection means selecting the most useful input variables for building a machine learning model.

Consider a model predicting house prices using five features:

- House area
- Number of bedrooms
- Location
- Wall colour
- House age

Suppose Lasso produces the following illustrative coefficients:

| Feature     | Coefficient before Lasso | Coefficient after Lasso |
| ----------- | ------------------------ | ----------------------- |
| House area  | 8.5                      | 7.2                     |
| Bedrooms    | 4.2                      | 3.1                     |
| Location    | 6.8                      | 5.4                     |
| Wall colour | 0.5                      | 0                       |
| House age   | 2.1                      | 1.3                     |

The coefficient of wall colour becomes zero.

Therefore, Lasso removes wall colour from the model.



Important concept

&#x20;Lasso performs automatic feature selection by setting some coefficients exactly to zero.



*Note: The values above are illustrative, not calculated from an actual dataset.*

### **5. Role of Lambda (λ)**

Lambda controls the strength of regularization.

| Lambda value      | Effect                                |
| ----------------- | ------------------------------------- |
| \\(\lambda=0\\)   | Ordinary Linear Regression            |
| Small λ           | Small coefficient penalty             |
| Large λ           | More coefficients shrink towards zero |
| Extremely large λ | May cause underfitting                |

### **6. Advantages of Lasso Regression**

1. Reduces overfitting.
2. Performs automatic feature selection.
3. Removes less important features by making coefficients zero.
4. Produces simpler and more interpretable models.
5. Useful when a dataset contains many input features.

### **7. Disadvantages of Lasso Regression**

1. May remove useful features if regularization is too strong.
2. Can be unstable when input features are highly correlated.
3. Choosing the correct lambda value can be difficult.
4. Excessive regularization can cause underfitting.
5. Feature scaling is important.

### **8. Applications of Lasso Regression**

- Medical diagnosis and disease prediction.
- Financial forecasting.
- House price prediction.
- Gene selection in biological datasets.
- Selecting important variables from large datasets.

### **9. Difference between Ridge and Lasso Regression**

| Ridge Regression                                               | Lasso Regression                                              |
| -------------------------------------------------------------- | ------------------------------------------------------------- |
| Uses L2 regularization.                                        | Uses L1 regularization.                                       |
| Penalty is \\(\lambda\sum\beta_j^2\\).                         | Penalty is \\(\lambda\sum\|\beta_j\|\\).                      |
| Shrinks coefficients towards zero.                             | Can make coefficients exactly zero.                           |
| Generally retains all features.                                | Performs automatic feature selection.                         |
| Useful when many correlated features contribute to prediction. | Useful when a simpler model with fewer features is desirable. |

### **10. Difference between Linear Regression and Lasso Regression**

| Linear Regression                          | Lasso Regression                          |
| ------------------------------------------ | ----------------------------------------- |
| No regularization penalty.                 | Uses L1 regularization.                   |
| Does not automatically eliminate features. | Can eliminate features.                   |
| Minimizes sum of squared errors.           | Minimizes squared errors plus L1 penalty. |
| Can overfit in some situations.            | Helps reduce overfitting.                 |

Lasso Regression is a regularized form of Linear Regression that uses L1 regularization to reduce overfitting. It adds the absolute values of coefficients to the loss function. It is useful when a dataset contains many features and we want to build a simpler and more interpretable model.
