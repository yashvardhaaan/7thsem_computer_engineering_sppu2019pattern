## **Topic 2.2.10: Evaluation Metrics for Regression**

### **1. What are Evaluation Metrics?**

**Evaluation Metrics** are mathematical measures used to evaluate how accurately a regression model predicts continuous numerical values.

They compare the actual values with the predicted values to determine the performance of the model.

**Example:** Suppose a model predicts house prices. We compare its predicted prices with the actual selling prices to measure how accurate the model is.

### **2. Why are Evaluation Metrics important?**

1. To measure prediction accuracy.
2. To compare different regression models.
3. To identify prediction errors.
4. To select the best-performing model.
5. To understand how well a model generalizes to unseen data.

### **3. Important Regression Evaluation Metrics**

The important metrics in your SPPU question papers are:

1. Mean Absolute Error (MAE)
2. Mean Squared Error (MSE)
3. Root Mean Squared Error (RMSE)
4. R-squared (R²)

## **4. Mean Absolute Error (MAE)**

**Definition:** Mean Absolute Error is the average of the absolute differences between actual values and predicted values.

It measures the average magnitude of prediction errors without considering their direction.

**Formula:**

\\[ \boxed{MAE=\frac{1}{n}\sum\_{i=1}^{n}|Y_i-\hat Y_i|} \\]

Where:

- \\(n\\) = Number of observations
- \\(Y_i\\) = Actual value
- \\(\hat Y_i\\) = Predicted value
- \\(|\ |\\) = Absolute value

**Example:**

Suppose actual and predicted values are:

| Actual (Y) | Predicted (Ŷ) | Absolute Error |
| ---------- | ------------- | -------------- |
| 100        | 90            | 10             |
| 200        | 210           | 10             |
| 300        | 280           | 20             |
| 400        | 390           | 10             |

\\[ MAE=\frac{10+10+20+10}{4} \\]

\\[ \boxed{MAE=12.5} \\]

**Interpretation:** The model's predictions are off by an average of 12.5 units.

**Advantages:**

- Easy to understand and calculate.
- Uses the same unit as the target variable.
- Less sensitive to large errors than MSE and RMSE.

**Disadvantages:**

- Does not penalize large errors as strongly as MSE.
- Does not indicate whether predictions are too high or too low.

## **5. Mean Squared Error (MSE)**

**Definition:** Mean Squared Error is the average of the squared differences between actual values and predicted values.

It penalizes larger prediction errors more heavily because errors are squared.

**Formula:**

\\[ \boxed{MSE=\frac{1}{n}\sum\_{i=1}^{n}(Y_i-\hat Y_i)^2} \\]

**Example:**

Using the same dataset:

| Actual (Y) | Predicted (Ŷ) | Error | Squared Error |
| ---------- | ------------- | ----- | ------------- |
| 100        | 90            | 10    | 100           |
| 200        | 210           | -10   | 100           |
| 300        | 280           | 20    | 400           |
| 400        | 390           | 10    | 100           |
| **Total**  |               |       | **700**       |

\\[ MSE=\frac{700}{4} \\]

\\[ \boxed{MSE=175} \\]

**Interpretation:** The average squared prediction error is 175 square units.

**Advantages:**

- Penalizes large errors more heavily.
- Useful for optimization because it is differentiable.
- Commonly used as a regression loss function.

**Disadvantages:**

- Sensitive to outliers.
- Its unit is the square of the target variable's unit.
- Less intuitive to interpret than MAE.

## **6. Root Mean Squared Error (RMSE)**

**Definition:** Root Mean Squared Error is the square root of the Mean Squared Error.

It measures the typical magnitude of prediction errors while penalizing large errors more heavily.

**Formula:**

\\[ \boxed{RMSE=\sqrt{\frac{1}{n} \sum\_{i=1}^{n}(Y_i-\hat Y_i)^2}} \\]

Or:

\\[ \boxed{RMSE=\sqrt{MSE}} \\]

**Example:**

From the previous calculation:

\\[ MSE=175 \\]

Therefore:

\\[ RMSE=\sqrt{175} \\]

\\[ \boxed{RMSE\approx13.23} \\]

**Interpretation:** The RMSE is approximately 13.23 units.

**Advantages:**

- Penalizes large errors more heavily.
- Expressed in the same unit as the target variable.
- Useful for comparing regression models on the same dataset.

**Disadvantages:**

- Sensitive to outliers.
- A single large error can significantly increase RMSE.
- Does not show the direction of prediction errors.

## **7. R-squared (R²)**

**Definition:** R-squared, also called the coefficient of determination, measures how much of the variation in the dependent variable is explained by the regression model.

**Formula:**

\\[ \boxed{R^2=1-\frac{SS\_{res}}{SS\_{tot}}} \\]

Where:

- \\(SS\_{res}\\) = Sum of squared residuals.
- \\(SS\_{tot}\\) = Total sum of squares.

\\[ SS\_{res}=\sum(Y_i-\hat Y_i)^2 \\]

\\[ SS\_{tot}=\sum(Y_i-\bar Y)^2 \\]

Here, \\(\bar Y\\) is the mean of actual values.

**Example:**

Suppose:

\\[ SS\_{res}=100 \\]

\\[ SS\_{tot}=500 \\]

Then:

\\[ R^2=1-\frac{100}{500} \\]

\\[ R^2=1-0.2 \\]

\\[ \boxed{R^2=0.8} \\]

Therefore, the model explains 80% of the variation in the dependent variable.

### **Interpretation of R²**

| R² value | Interpretation                                                         |
| -------- | ---------------------------------------------------------------------- |
| 1        | Perfect fit                                                            |
| 0.8      | Explains 80% of variation                                              |
| 0.5      | Explains 50% of variation                                              |
| 0        | No improvement over predicting the mean, under the standard definition |
| Negative | Performs worse than predicting the mean on the evaluated data          |

**Important:** A high R² does not automatically mean the model is good. It can still overfit or perform poorly on unseen data.

## **8. Comparison of MAE, MSE, RMSE and R²**

| Metric | Measures                             | Better result    |
| ------ | ------------------------------------ | ---------------- |
| MAE    | Average absolute error               | Lower            |
| MSE    | Average squared error                | Lower            |
| RMSE   | Square root of average squared error | Lower            |
| R²     | Variation explained by model         | Generally higher |

**Remember:**

- MAE: Average absolute error.
- MSE: Average squared error.
- RMSE: Square root of MSE.
- R²: Percentage of variation explained by the model.

## **9. Difference between MAE, MSE and RMSE**

| MAE                         | MSE                           | RMSE                                    |
| --------------------------- | ----------------------------- | --------------------------------------- |
| Uses absolute errors.       | Uses squared errors.          | Square root of squared errors' average. |
| Less sensitive to outliers. | Highly sensitive to outliers. | Highly sensitive to outliers.           |
| Same unit as target.        | Squared unit.                 | Same unit as target.                    |
| Easy to interpret.          | Less intuitive.               | Easier to interpret than MSE.           |

## **10. Why is RMSE preferred over MSE?**

This is an important SPPU examination question.

**Advantages of RMSE over MSE:**

1. RMSE is expressed in the same unit as the actual output variable.
2. It is easier to understand and interpret.
3. It penalizes larger prediction errors more heavily.
4. It helps compare regression models using the same dataset and target scale.
5. It gives an estimate of typical prediction-error magnitude.

**Example:** If the target variable is house price in rupees, MSE is expressed in squared rupees, whereas RMSE is expressed in rupees.

## **11. Combined numerical example**

Consider the following data:

| Actual Y | Predicted Ŷ |
| -------- | ----------- |
| 10       | 8           |
| 20       | 22          |
| 30       | 27          |
| 40       | 38          |

Calculate MAE, MSE and RMSE.

**Step 1: Prepare the table**

| Y         | Ŷ  | Absolute error | Squared error |
| --------- | -- | -------------- | ------------- |
| 10        | 8  | 2              | 4             |
| 20        | 22 | 2              | 4             |
| 30        | 27 | 3              | 9             |
| 40        | 38 | 2              | 4             |
| **Total** |    | **9**          | **21**        |

**Step 2: Calculate MAE**

\\[ MAE=\frac{9}{4} \\]

\\[ \boxed{MAE=2.25} \\]

**Step 3: Calculate MSE**

\\[ MSE=\frac{21}{4} \\]

\\[ \boxed{MSE=5.25} \\]

**Step 4: Calculate RMSE**

\\[ RMSE=\sqrt{5.25} \\]

\\[ \boxed{RMSE\approx2.29} \\]

Final answers:

- MAE = 2.25
- MSE = 5.25
- RMSE = 2.29
