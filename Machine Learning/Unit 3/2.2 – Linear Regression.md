## **2.2.1 What is Linear Regression?**

**Definition (SPPU exam-ready):**

Linear Regression is a supervised machine learning algorithm used to predict a continuous dependent variable by establishing a linear relationship between one or more independent variables.

In simple words, Linear Regression finds the best-fitting straight line through the given data points to predict numerical values.

**Examples:**

- Predicting marks based on study hours.
- Predicting house prices based on area.
- Predicting salary based on years of experience.
- Predicting expenditure based on month.
- Predicting sales based on advertising expenditure.

## **2.2.2 Why is Linear Regression used?**

Suppose a company has collected the following data:

| Advertising expenditure (₹ thousands) | Sales (₹ thousands) |
| ------------------------------------- | ------------------- |
| 1                                     | 10                  |
| 2                                     | 20                  |
| 3                                     | 30                  |
| 4                                     | 40                  |
| 5                                     | 50                  |

The company wants to predict sales when advertising expenditure is ₹6,000.

Instead of manually calculating the answer every time, Linear Regression learns the relationship between advertising expenditure and sales.

It uses that relationship to predict sales for a new input.

## **2.2.3 Working of Linear Regression**

The basic working process consists of the following steps:

**1. Collect Training Data**

Independent variable X and dependent variable Y

**2. Plot the Data Points**

Observe the relationship between X and Y

**3. Find the Best-Fit Straight Line**

Estimate the line's slope and intercept

**4. Train the Model**

Learn the coefficients from the data

**5. Predict New Values**

Generate numerical predictions

## **2.2.6 Important characteristics**

1. Linear Regression is a supervised learning algorithm.
2. It is used for predicting continuous numerical outputs.
3. It learns the relationship between independent and dependent variables.
4. It fits a straight line to the observed data in the basic linear model.
5. It can be used for prediction and trend analysis.
6. The fitted line is generally selected by minimizing the sum of squared residuals.

## **2.2.7 Advantages and limitations**

| Advantages                          | Limitations                                                  |
| ----------------------------------- | ------------------------------------------------------------ |
| Simple to understand and implement. | May not fit complex nonlinear relationships.                 |
| Easy to interpret coefficients.     | Sensitive to outliers.                                       |
| Computationally efficient.          | Can be affected by multicollinearity in multiple regression. |
| Useful for numerical prediction.    | Relies on assumptions about the relationship and errors.     |
