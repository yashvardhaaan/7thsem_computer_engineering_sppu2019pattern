# **3. GENERALIZATION IN MACHINE LEARNING**

## **3.1 What is Generalization?**

**Definition (Exam-ready):**

Generalization is the ability of a machine learning model to perform accurately on new, unseen data that was not used during the training process.

In simple language:

Generalization means that a model should not simply memorize the training data. It should learn the underlying patterns so that it can make accurate predictions on new data.

### **3.2 Understand with a real-life example**

Suppose you are preparing for your Machine Learning examination.

There are two students:

**Student A – Memorization**

- Memorizes answers to previous year questions.
- Can answer questions that appeared in previous papers.
- Struggles when new questions are asked.
- Has learned specific answers rather than concepts.

**Student B – Understanding**

- Understands the concepts.
- Practises different types of questions.
- Can solve unfamiliar questions.
- Applies knowledge to new problems.

Student B demonstrates better generalization.

The same principle applies to machine learning models.

A good machine learning model should learn patterns instead of memorizing individual training examples.

## **3.3 How Generalization works**

Machine learning generally divides available data into three parts.

## **Dataset division**

**1. Training Dataset**

# **70%**

Used to train the machine learning model and learn patterns.

**2. Validation Dataset**

# **15%**

Used to tune model parameters and select the best model.

**3. Testing Dataset**

# **15%**

Used to evaluate performance on unseen data.

Illustrative split: 70:15:15. Other splits can also be used.

**Working:**

1. The training dataset is provided to the model.
2. The model learns patterns and relationships.
3. The validation dataset helps tune the model.
4. The testing dataset evaluates performance on unseen examples.
5. If the model performs well on unseen data, it demonstrates good generalization.

## **3.4 Training Error**

**Definition:**

Training error is the difference between the actual output and the predicted output of a machine learning model on the training dataset.

In simple language, it measures how many mistakes the model makes on the data it has already learned from.

**Example:**

Suppose a model predicts examination marks:

| Student | Actual marks | Predicted marks |
| ------- | ------------ | --------------- |
| A       | 90           | 88              |
| B       | 80           | 78              |
| C       | 70           | 68              |
| D       | 60           | 58              |

The differences between actual and predicted marks represent prediction errors.

These errors are used to calculate training error.

**Important:** Lower training error generally indicates that the model fits its training data better. However, it does not guarantee good performance on new data.

## **3.5 Generalization Error**

**Definition:**

Generalization error is the error made by a trained machine learning model when predicting outcomes for new, unseen data drawn from the target data distribution.

In simple language, it measures how well a model performs on data it has never seen before.

**Example:**

Suppose the model is trained using 100 students' records.

After training, we test it on 20 new students.

If its predictions are significantly different from their actual marks, the model has high generalization error.

If its predictions are close to the actual marks, it has low generalization error.

## **3.6 Difference between Training Error and Generalization Error**

Important – 6 marks preparation

| Training Error                                                      | Generalization Error                                                           |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| Error calculated on training data.                                  | Error on unseen data from the target distribution.                             |
| Measures how well the model fits training data.                     | Measures how well the model performs on new data.                              |
| Calculated during model training.                                   | Estimated using validation or test data.                                       |
| Usually decreases as model complexity increases.                    | May increase if the model overfits.                                            |
| Low training error does not guarantee good predictions on new data. | Low generalization error indicates good predictive performance on unseen data. |
| Helps evaluate training fit.                                        | Helps evaluate generalization ability.                                         |

## **3.7 Relationship between Training Error and Generalization Error**

Consider these two situations.

**Situation 1: Good Generalization**

- Training error is low.
- Testing error is also low.
- The model learns useful patterns.
- The model performs well on unseen data.

**Situation 2: Poor Generalization**

- Training error is very low.
- Testing error is high.
- The model memorizes training examples.
- The model fails to perform well on new data.

The difference between training error and testing/generalization error is commonly called the generalization gap.

\\[ \text{Generalization Gap} = E\_{\text{test}}-E\_{\text{train}} \\]

This expression is a practical estimate using test error, not the exact theoretical generalization error.

## **3.8 Factors Affecting Generalization**

1\. **Training Data Quality:** Poor-quality or noisy data can affect the model's ability to learn useful patterns.

2\. **Training Data Quantity:** Insufficient data can make the model learn unreliable patterns.

3\. **Model Complexity:** An unnecessarily complex model may memorize training data.

4\. **Feature Selection:** Irrelevant features can negatively affect model performance.

5\. **Regularization:** Regularization controls model complexity and helps prevent overfitting.

6\. **Cross-Validation:** Helps evaluate model performance across different data subsets.

## **3.9 Techniques to Improve Generalization**

| Technique                   | Explanation                                                      |
| --------------------------- | ---------------------------------------------------------------- |
| More training data          | Helps the model learn representative patterns.                   |
| Regularization              | Penalizes unnecessary model complexity.                          |
| Cross-validation            | Evaluates performance across different data splits.              |
| Feature selection           | Removes irrelevant features.                                     |
| Early stopping              | Stops training when validation performance begins deteriorating. |
| Data augmentation           | Creates additional varied training examples where appropriate.   |
| Appropriate model selection | Selects a model with suitable complexity.                        |

# **3.11 Exam-ready Answer (6 Marks)**

**Q. Write a short note on Training Error and Generalization Error in Machine Learning.**

**1. Training Error:**

Training error is the difference between actual and predicted outputs on the training dataset. It measures how well the model fits the training data.

**2. Generalization Error:**

Generalization error measures the prediction error of a trained model on new, unseen data. It indicates the ability of a model to perform accurately on unknown examples.

**3. Difference:**

| Training Error                         | Generalization Error                     |
| -------------------------------------- | ---------------------------------------- |
| Calculated on training data.           | Evaluated on unseen data.                |
| Measures training performance.         | Measures predictive performance.         |
| Low error indicates good training fit. | Low error indicates good generalization. |

**4. Importance:**

- Helps evaluate model performance.
- Identifies overfitting and underfitting.
- Helps select an appropriate model.
- Helps improve prediction accuracy on unseen data.

**Conclusion:**

A good machine learning model should have low training error and low generalization error so that it can perform accurately on both training and unseen data.

# **3.12 Quick Revision**

**Five important points to remember**

1. Generalization means performing well on unseen data.
2. Training error measures performance on training data.
3. Generalization error measures performance on new data.
4. The generalization gap indicates the difference between training and test errors.
5. Regularization, cross-validation and appropriate model selection help improve generalization.
