# 14.1 What Is SAT?

**SAT** stands for:

> **Boolean Satisfiability Problem**

Given a Boolean formula containing variables, the SAT problem asks:

> **Is there an assignment of TRUE/FALSE values to the variables that makes the entire formula TRUE?**

The answer is:

```text
YES
```

or:

```text
NO
```

---

# 14.2 Example of SAT

Consider:

```text
(x₁ ∨ x₂) ∧ (¬x₁ ∨ x₃)
```

Try the assignment:

```text
x₁ = TRUE
x₂ = FALSE
x₃ = TRUE
```

First clause:

```text
(x₁ ∨ x₂)
= TRUE ∨ FALSE
= TRUE
```

Second clause:

```text
(¬x₁ ∨ x₃)
= FALSE ∨ TRUE
= TRUE
```

Therefore the complete formula is TRUE.

So the answer is:

```text
YES
```

The formula is **satisfiable**.

---

# 14.3 What Does "Satisfiable" Mean?

A Boolean formula is **satisfiable** if there exists at least one assignment of truth values that makes the formula TRUE.

For example:

```text
x₁ ∨ x₂
```

is satisfiable because:

```text
x₁ = TRUE
```

makes the formula TRUE.

---

# 14.4 What Is an Unsatisfiable Formula?

A formula is **unsatisfiable** if no possible assignment makes it TRUE.

Example:

```text
x ∧ ¬x
```

If:

```text
x = TRUE
```

then:

```text
¬x = FALSE
```

so:

```text
TRUE ∧ FALSE = FALSE
```

If:

```text
x = FALSE
```

then:

```text
FALSE ∧ TRUE = FALSE
```

Therefore no assignment satisfies the formula.

So:

```text
x ∧ ¬x
```

is unsatisfiable.

---

# 14.5 Boolean Variables

A Boolean variable can have only two values:

```text
TRUE
FALSE
```

For example:

```text
x₁ = TRUE
x₂ = FALSE
```

---

# 14.6 Literals

A **literal** is either:

* A Boolean variable.
* The negation of a Boolean variable.

Examples:

```text
x₁
x₂
¬x₃
¬x₄
```

Therefore:

```text
x₁
```

is a positive literal, while:

```text
¬x₁
```

is a negative literal.

---

# 14.7 Clause

A **clause** is a disjunction (`OR`) of literals.

Example:

```text
(x₁ ∨ x₂ ∨ ¬x₃)
```

This is one clause containing three literals.

A clause is TRUE if at least one of its literals is TRUE.

---

# 14.8 Conjunctive Normal Form — CNF

3-SAT is normally expressed in **Conjunctive Normal Form (CNF)**.

CNF means:

> AND of OR clauses.

General form:

```text
Clause₁ ∧ Clause₂ ∧ Clause₃ ∧ ...
```

For example:

```text
(x₁ ∨ x₂ ∨ ¬x₃)
∧
(¬x₁ ∨ x₄ ∨ x₅)
```

Each clause uses OR:

```text
∨
```

and the clauses are connected using AND:

```text
∧
```

---

# 14.9 What Is 3-SAT?

**3-SAT** is a restricted version of SAT.

In 3-SAT:

> Every clause contains exactly three literals.

Example:

```text
(x₁ ∨ x₂ ∨ ¬x₃)
∧
(¬x₁ ∨ x₄ ∨ x₅)
∧
(x₂ ∨ ¬x₄ ∨ x₆)
```

Each clause contains three literals.

The question is:

> Is there an assignment of TRUE/FALSE values that satisfies all clauses?

---

# 14.10 General Structure of 3-SAT

A 3-SAT formula can be represented as:

```text
C₁ ∧ C₂ ∧ C₃ ∧ ... ∧ Cₘ
```

where every clause has the form:

```text
(l₁ ∨ l₂ ∨ l₃)
```

and each `lᵢ` is a literal.

Therefore:

```text
3-SAT = AND of 3-literal OR clauses
```

---

# 14.11 Example of 3-SAT

Consider:

```text
(x₁ ∨ x₂ ∨ ¬x₃)
∧
(¬x₁ ∨ x₄ ∨ x₅)
```

There are two clauses:

### Clause 1

```text
x₁ ∨ x₂ ∨ ¬x₃
```

### Clause 2

```text
¬x₁ ∨ x₄ ∨ x₅
```

Each contains exactly three literals.

Therefore this is a 3-SAT formula.

---

# 14.12 Solving a Simple 3-SAT Example

Consider:

```text
(x₁ ∨ x₂ ∨ ¬x₃)
∧
(¬x₁ ∨ x₂ ∨ x₃)
```

Choose:

```text
x₁ = TRUE
x₂ = TRUE
x₃ = FALSE
```

First clause:

```text
TRUE ∨ TRUE ∨ TRUE
= TRUE
```

Second clause:

```text
FALSE ∨ TRUE ∨ FALSE
= TRUE
```

Therefore:

```text
YES
```

The formula is satisfiable.

---

# 14.13 3-SAT as a Decision Problem

The formal 3-SAT problem asks:

> Given a Boolean formula in 3-CNF, is there an assignment of truth values that satisfies the formula?

The output is:

```text
YES / NO
```

This decision version is:

```text
3-SAT ∈ NP
```

and:

```text
3-SAT is NP-Complete
```

---

# 14.14 Why Is 3-SAT in NP?

Suppose someone gives us a candidate assignment:

```text
x₁ = TRUE
x₂ = FALSE
x₃ = TRUE
...
```

We can check every clause.

For each clause:

```text
(l₁ ∨ l₂ ∨ l₃)
```

we evaluate its three literals.

The entire formula is satisfied if every clause is TRUE.

Since each clause can be checked efficiently and there are `m` clauses:

```text
Verification = O(m)
```

apart from representation details.

Therefore verification is polynomial.

Hence:

```text
3-SAT ∈ NP
```

---

# 14.15 Why Is 3-SAT NP-Hard?

To establish NP-Hardness, we can use the known NP-Complete problem SAT.

SAT is NP-Complete due to the **Cook-Levin theorem**.

We can transform a SAT instance into an equivalent 3-SAT instance in polynomial time:

```text
SAT ≤p 3-SAT
```

Therefore 3-SAT is NP-Hard.

Since:

```text
3-SAT ∈ NP
```

and:

```text
3-SAT is NP-Hard
```

we conclude:

```text
3-SAT is NP-Complete
```

---

# 14.16 Proof That 3-SAT Is NP-Complete

The standard proof has two parts.

## Part 1 — 3-SAT ∈ NP

Given a truth assignment, verify every clause in polynomial time.

Therefore:

```text
3-SAT ∈ NP
```

---

## Part 2 — 3-SAT Is NP-Hard

SAT is NP-Complete.

Reduce SAT to 3-SAT:

```text
SAT ≤p 3-SAT
```

The transformation takes polynomial time and preserves satisfiability.

Therefore:

```text
3-SAT is NP-Hard
```

---

## Conclusion

Therefore:

```text
3-SAT ∈ NP
+
3-SAT is NP-Hard
```

Hence:

```text
3-SAT is NP-Complete
```

---

```text
             3-SAT

       ┌───────┴────────┐

       │                │
```

# 14.18 SAT ≤p 3-SAT

The reduction:

```text
SAT ≤p 3-SAT
```

means:

> Every SAT instance can be transformed into an equivalent 3-SAT instance in polynomial time.

The transformation modifies clauses so that every clause has exactly three literals.

The resulting formula is satisfiable if and only if the original formula is satisfiable.

---

# 14.19 Why Do We Need a Reduction?

SAT already contains clauses of arbitrary length.

For example:

```text
(x₁ ∨ x₂ ∨ x₃ ∨ x₄ ∨ x₅)
```

is valid SAT.

But it is not a valid 3-SAT clause because it contains five literals.

We need to transform it into an equivalent collection of clauses containing three literals each.

---

# 14.20 Converting Long Clauses to 3-SAT

Consider:

```text
(x₁ ∨ x₂ ∨ x₃ ∨ x₄)
```

Introduce a new variable `y`.

One equivalent 3-CNF construction is:

```text
(x₁ ∨ x₂ ∨ y)
∧
(¬y ∨ x₃ ∨ x₄)
```

The new variable allows the original long clause to be represented using 3-literal clauses.

The transformation is polynomial.

---

# 14.21 Another Example

Suppose we have:

```text
(x₁ ∨ x₂ ∨ x₃ ∨ x₄ ∨ x₅)
```

Introduce new variables:

```text
y₁, y₂
```

and construct:

```text
(x₁ ∨ x₂ ∨ y₁)
∧
(¬y₁ ∨ x₃ ∨ y₂)
∧
(¬y₂ ∨ x₄ ∨ x₅)
```

Now every clause has exactly three literals.

The transformation remains polynomial.

---

# 14.22 Why New Variables Are Used

The additional variables are called **auxiliary variables**.

They help break long clauses into multiple 3-literal clauses.

They are chosen so that:

```text
Original formula satisfiable
          ⇔
New 3-SAT formula satisfiable
```

The exact values of auxiliary variables do not matter as long as this equivalence is maintained.

---

# 14.23 Clauses With Fewer Than Three Literals

If the SAT formula contains clauses with fewer than three literals, they can also be transformed into 3-literal clauses using appropriate auxiliary variables or repeated literals, depending on the formulation.

For example:

```text
(x₁)
```

can conceptually be represented as:

```text
(x₁ ∨ x₁ ∨ x₁)
```

and:

```text
(x₁ ∨ x₂)
```

can be represented as:

```text
(x₁ ∨ x₂ ∨ x₂)
```

depending on the definition being used.

| ----------------------------------------------- | --------------------------------------- |
| General Boolean satisfiability                  | Restricted Boolean satisfiability       |

# 14.26 2022 PYQ — 3-SAT Answer

```text
(x₁ ∨ x₂ ∨ ¬x₃)

(¬x₁ ∨ x₄ ∨ x₅)
```




# 14.27 Why Is SAT Important?

SAT is extremely important in theoretical computer science because:

1. SAT was the first problem proven to be NP-Complete.
2. It provides a foundation for NP-Completeness theory.
3. Many NP-Complete problems can be proved NP-Complete through reductions from SAT.
4. It helps classify computationally difficult problems.
5. It is used in logic, verification, planning and constraint solving.

# 14.28 Cook-Levin Theorem

The **Cook-Levin theorem** states:

> **Boolean SAT is NP-Complete.**

This was a foundational result in computational complexity.

It establishes that:

```text
SAT ∈ NP
```

and:

```text
Every problem in NP can be
polynomially reduced to SAT.
```

Therefore:

```text
SAT is NP-Complete
```

# 14.32 2025 PYQ — Answer

## 3-SAT

3-SAT is a Boolean satisfiability problem where every clause contains exactly three literals.

Example:

```text
(x₁ ∨ ¬x₂ ∨ x₃)
∧
(¬x₁ ∨ x₂ ∨ x₄)
```

A solution is an assignment of TRUE/FALSE values to the variables such that every clause evaluates to TRUE.

For example:

```text
x₁ = TRUE
x₂ = TRUE
x₃ = TRUE
x₄ = TRUE
```

First clause:

```text
TRUE ∨ FALSE ∨ TRUE
= TRUE
```

Second clause:

```text
FALSE ∨ TRUE ∨ TRUE
= TRUE
```

Therefore the formula is satisfiable.

3-SAT is an NP-Complete problem.

---

# 14.33 Why 3-SAT Is Used in Reductions

3-SAT has a useful structure:

```text
AND
 ↓
OR clauses
 ↓
Exactly 3 literals
```

This makes it convenient for constructing gadgets and reductions to other problems.

For example:

```text
3-SAT
  ↓
Vertex Cover
```

or:

```text
3-SAT
  ↓
Clique
```

or:

```text
3-SAT
  ↓
Hamiltonian Cycle
```

These reductions help establish NP-Hardness.

---

# 14.34 3-SAT and Vertex Cover

One common theoretical relationship is:

```text
3-SAT ≤p Vertex Cover
```

This means a 3-SAT instance can be transformed into a graph and integer `k` such that:

```text
3-SAT satisfiable
        ⇔
Graph has vertex cover of size ≤ k
```

This type of reduction is used to establish that Vertex Cover is NP-Hard.

---

# 14.35 3-SAT and Hamiltonian Cycle

Another classic result involves reducing a known NP-Complete problem such as 3-SAT to Hamiltonian Cycle.

Conceptually:

```text
3-SAT formula
      ↓
Polynomial transformation
      ↓
Graph
      ↓
Hamiltonian Cycle?
```

The graph is constructed so that:

```text
Formula satisfiable
      ⇔
Graph has Hamiltonian Cycle
```

This establishes NP-Hardness.

# 14.36 3-SAT and Computational Complexity

3-SAT demonstrates an important complexity-theory principle:

> Restricting a problem does not necessarily make it efficiently solvable.

SAT is general Boolean satisfiability.

3-SAT is a restricted version.

Yet:

```text
SAT → NP-Complete
3-SAT → NP-Complete
```

So even the restricted 3-SAT form remains computationally difficult.

---

# 14.37 Brute-Force Solution

Suppose there are `n` Boolean variables.

Each variable has two possible values:

```text
TRUE
FALSE
```

Therefore there are:

```text
2ⁿ
```

possible assignments.

A brute-force algorithm can:

1. Generate all assignments.
2. Evaluate the formula for each assignment.
3. Return YES if one assignment satisfies all clauses.

Worst-case complexity is exponential:

```text
O(2ⁿ · m)
```

where `m` is the number of clauses.

---

# 14.38 Why Brute Force Becomes Difficult

For:

```text
n = 10
```

possible assignments:

```text
2¹⁰ = 1024
```

For:

```text
n = 50
```

possible assignments:

```text
2⁵⁰
```

which is already enormous.

For:

```text
n = 100
```

the search space is:

```text
2¹⁰⁰
```

This illustrates why brute-force SAT/3-SAT solving does not scale well in the general case.

---

# 14.39 Practical SAT Solvers

Although 3-SAT is NP-Complete, modern SAT solvers can solve many real-world instances efficiently.

They use techniques such as:

* Backtracking
* Boolean constraint propagation
* Conflict-driven clause learning
* Heuristics
* Variable selection strategies

This does not contradict NP-Completeness.

NP-Completeness describes the **worst-case complexity** of the general problem.

---

# 14.40 Important Exam Distinction

Do not write:

> "3-SAT cannot be solved."

Instead write:

> **3-SAT is NP-Complete, meaning no polynomial-time algorithm is currently known for the general problem.**

# 14.41 Common Mistakes

## Mistake 1 — 3-SAT means three variables

Wrong.

It means:

> Each clause contains three literals.

A formula may contain many variables.

---

## Mistake 2 — Every clause contains three different variables

Not necessarily.

A clause contains three literals. Depending on the formal formulation, repeated literals may be possible.

---

## Mistake 3 — 3-SAT is not in NP

Wrong.

```text
3-SAT ∈ NP
```

because a candidate assignment can be verified in polynomial time.

---

## Mistake 4 — 3-SAT is only NP-Hard

Incomplete.

3-SAT is both:

```text
NP
```

and:

```text
NP-Hard
```

Therefore:

```text
3-SAT is NP-Complete
```

---

## Mistake 5 — Wrong reduction direction

To prove 3-SAT is NP-Hard, use a known NP-Complete problem such as SAT:

```text
SAT ≤p 3-SAT
```

not:

```text
3-SAT ≤p SAT
```

for that particular NP-Hardness argument.
