## 1. What are Ishikawa's 7 Basic Tools?

Ishikawa's Seven Basic Quality Tools are a collection of simple graphical and statistical techniques used to identify, analyse and solve quality-related problems in an organisation.

These tools are associated with quality control expert Kaoru Ishikawa and help organisations identify defects, understand their causes and improve processes.

In Software Quality Assurance, these tools help identify software defects, analyse their causes and improve software development and testing processes.

## 2. Seven Basic Tools of Quality Control

The seven tools are:

1. Cause-and-Effect Diagram (Fishbone Diagram)
2. Check Sheet
3. Control Chart
4. Histogram
5. Pareto Chart
6. Scatter Diagram
7. Flowchart (Stratification is used in some traditional lists instead of Flowchart).

## 3. Comparison: Flowchart vs Histogram

Repeated PYQ – 4 appearances

| Basis            | Flowchart                                   | Histogram                                          |
| ---------------- | ------------------------------------------- | -------------------------------------------------- |
| Meaning          | Graphical representation of process steps   | Graphical representation of frequency distribution |
| Purpose          | Understand process sequence                 | Analyse data distribution                          |
| Nature           | Process-oriented                            | Data-oriented                                      |
| Structure        | Uses symbols and arrows                     | Uses adjacent rectangular bars                     |
| Data requirement | Does not require numerical data             | Requires numerical data                            |
| Main use         | Identify process gaps and unnecessary steps | Identify variation and data patterns               |
| Example          | Login process workflow                      | Distribution of response times                     |

Conclusion: A flowchart explains how a process works, whereas a histogram explains how numerical data is distributed.

1. Help identify and analyse quality problems.

4. Help identify root causes of problems.
5. Improve process efficiency and productivity.
6. Support continuous quality improvement.

Ishikawa's Seven Basic Quality Tools are useful techniques for identifying, analysing and solving quality-related problems. In Software Quality Assurance, they help monitor processes, identify root causes of defects and improve software quality.
