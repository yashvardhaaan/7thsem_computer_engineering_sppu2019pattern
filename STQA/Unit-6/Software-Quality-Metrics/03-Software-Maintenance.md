Question: What is Software Maintenance? Explain in detail. (Q7 c)

## 1. Definition

Software Maintenance is the process of modifying, updating, and improving software after its delivery to correct errors, adapt it to changing environments, improve performance, or add new features.

It ensures that software continues to work correctly and meets users' requirements throughout its life cycle.

Example: Updating a banking application to fix a payment failure, support a new operating system, or add UPI payment functionality.

## 3. Software Maintenance Process

The maintenance process generally involves the following steps:

1\. Change Request

User reports a defect or requests a modification.

2\. Impact Analysis

Analyse cost, risk, feasibility and affected modules.

3\. Modification

Modify the software design or source code.

4\. Testing

Perform unit, integration and regression testing.

5\. Deployment

Release the modified software to users.

6\. Review and Documentation

Verify the change and update documentation.

## 4. Importance / Advantages of Software Maintenance

1. Improves reliability: Fixes errors and prevents unexpected failures.
2. Enhances performance: Improves speed and resource utilisation.
3. Increases security: Fixes vulnerabilities and updates dependencies.
4. Supports changing requirements: Adapts software to new business needs.
5. Extends software life: Keeps software useful for a longer period.
6. Improves user satisfaction: Provides better functionality and usability.

## 5. Difference Between the Four Types

| Type       | Main purpose                  | Example         |
| ---------- | ----------------------------- | --------------- |
| Corrective | Fix existing errors           | Fix payment bug |
| Adaptive   | Adjust to environment changes | Support new OS  |
| Perfective | Improve features/performance  | Add new feature |
| Preventive | Avoid future problems         | Refactor code   |

## 6. Conclusion

Software maintenance is an essential activity performed after software delivery. It helps correct defects, adapt to environmental changes, improve functionality, and prevent future problems. The four major types are corrective, adaptive, perfective, and preventive maintenance.
