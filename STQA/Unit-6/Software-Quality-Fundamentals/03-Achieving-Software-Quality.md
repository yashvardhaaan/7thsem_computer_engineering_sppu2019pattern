## 2. What is Software Quality?

Software Quality refers to the degree to which a software product satisfies specified requirements, customer expectations and established quality standards.

Good-quality software should be reliable, efficient, secure, maintainable and easy to use.

## 3. Parameters Required for Achieving Good Software Quality

1\. Correctness

- Software should perform the functions according to specified requirements.
- It should produce accurate results.

Example: A banking application should calculate account balances correctly.

2\. Reliability

- Software should operate consistently without failures.
- It should provide correct results under specified conditions.

Example: An online banking system should process transactions reliably.

3\. Efficiency

- Software should use system resources such as CPU, memory and network efficiently.
- It should provide good response time.

Example: An application should load pages quickly without excessive memory consumption.

4\. Usability

- Software should be easy to learn, understand and operate.
- It should provide a user-friendly interface.

Example: A shopping application should provide simple navigation and an easy checkout process.

5\. Maintainability

- Software should be easy to modify, correct and update.
- Proper documentation and modular design improve maintainability.

Example: Developers should be able to update the payment module without affecting the login module.

6\. Security

- Software should protect data from unauthorised access and attacks.
- It should provide authentication, authorisation and data protection.

Example: A banking application should securely store customer information.

7\. Portability

- Software should be capable of operating on different platforms with minimal changes.
- It should support different operating systems and environments.

Example: An application should work on Windows and Linux.

8\. Scalability

- Software should handle increasing users, data and workload.
- It should maintain acceptable performance as demand increases.

Example: An e-commerce application should handle increased traffic during festival sales.

## 4. Activities Required to Achieve High Software Quality

1\. Requirement Analysis

- Understand customer requirements clearly.
- Identify functional and non-functional requirements.
- Avoid ambiguity in requirements.

2\. Quality Planning

- Prepare an SQA Plan.
- Define quality objectives, standards and procedures.
- Assign quality responsibilities to team members.

3\. Proper Software Design

- Use modular architecture and good design principles.
- Ensure maintainability, scalability and reliability.
- Review the design before implementation.

4\. Coding Standards

- Follow standard coding guidelines.
- Write readable, reusable and maintainable code.
- Perform code reviews to identify errors.

5\. Software Testing

- Perform unit, integration, system and acceptance testing.
- Conduct functional and non-functional testing.
- Identify and correct defects before release.

6\. Quality Reviews and Audits

- Conduct regular design and code reviews.
- Perform quality audits to verify compliance with standards.
- Identify process-related problems.

7\. Configuration and Change Management

- Maintain proper versions of source code and documents.
- Control changes in requirements and software components.
- Prevent errors caused by uncontrolled modifications.

8\. Continuous Improvement

- Collect customer feedback.
- Analyse defects and performance metrics.
- Improve development and testing processes regularly.

## 6. Benefits of Achieving Good Software Quality

1. Increases customer satisfaction.
2. Improves software reliability and performance.
3. Reduces defects and maintenance costs.
4. Improves security and data protection.
5. Increases software life and maintainability.
6. Improves organisational reputation.
7. Reduces development risks.

## 7. Conclusion

Achieving software quality requires proper requirement analysis, quality planning, good software design, coding standards, testing, reviews and continuous improvement. Important quality parameters such as correctness, reliability, efficiency, usability, security and maintainability ensure that software satisfies customer requirements and delivers dependable performance.

Exam tip

For a 6-mark answer, remember these two groups separately:

- Quality parameters: Correctness, Reliability, Efficiency, Usability, Maintainability, Security, Portability and Scalability.
- Quality activities: Requirements, Planning, Design, Coding, Testing, Reviews, Configuration Management and Continuous Improvement.

Important: Parameters describe what makes software good, whereas activities describe what an organisation does to achieve good software. This distinction will help you answer all three question variations correctly.
