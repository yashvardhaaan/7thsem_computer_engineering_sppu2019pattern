## Q1. Differentiate between Quality Assurance and Quality Control. (Nov 2022, Nov 2024 – 6 Marks)

### Difference between QA and QC

Quality Assurance (QA): It is a process-oriented activity that focuses on preventing defects by improving the software development processes.

Quality Control (QC): It is a product-oriented activity that focuses on identifying defects in the developed software through testing and inspection.

| Quality Assurance (QA)                                       | Quality Control (QC)                                               |
| ------------------------------------------------------------ | ------------------------------------------------------------------ |
| 1. QA focuses on preventing defects.                         | 1. QC focuses on identifying defects.                              |
| 2. It is process-oriented.                                   | 2. It is product-oriented.                                         |
| 3. It focuses on improving development processes.            | 3. It focuses on checking the quality of the product.              |
| 4. It is performed throughout the development lifecycle.     | 4. It is performed on software work products and builds.           |
| 5. It is a proactive approach.                               | 5. It is a reactive approach.                                      |
| 6. It involves process audits and standards.                 | 6. It involves testing and inspection.                             |
| 7. It is generally the responsibility of the entire team.    | 7. It is generally performed by testing and quality control teams. |
| 8. Example: Defining coding standards and review procedures. | 8. Example: Executing test cases to find software defects.         |

Conclusion: QA prevents defects by improving processes, whereas QC identifies defects by checking the actual software product.

## Q2. Explain Quality Assurance. (May 2025 – 6 Marks)

Definition:

Quality Assurance (QA) is a systematic process used to ensure that software development activities follow defined standards, procedures and methodologies to produce high-quality software.

It focuses on preventing defects rather than detecting them after development.

Objectives of Quality Assurance:

1. To prevent defects during software development.
2. To improve software development processes.
3. To ensure compliance with quality standards.
4. To improve customer satisfaction.
5. To maintain software reliability and quality.

Activities of Quality Assurance:

1\. Process Definition: Establishes standard procedures for software development.

2\. Process Audits: Checks whether development activities follow defined standards.

3\. Standards and Guidelines: Defines coding standards, documentation standards and development guidelines.

4\. Reviews: Reviews requirements, design documents and development processes to identify potential problems.

5\. Training: Provides training to developers and testers to improve their skills and knowledge.

6\. Continuous Improvement: Identifies weaknesses in existing processes and improves them.

Example:

Consider a company developing an online banking application.

The QA team:

- Defines coding standards for developers.
- Establishes code review procedures.
- Ensures secure development practices.
- Defines testing guidelines.
- Conducts process audits.

These activities help prevent defects before the software is delivered.

Advantages:

1. Reduces the number of software defects.
2. Improves development processes.
3. Reduces software maintenance costs.
4. Improves customer satisfaction.
5. Ensures consistent software quality.

Conclusion: Quality Assurance ensures that proper processes and standards are followed throughout software development to prevent defects and improve product quality.

## Q3. Explain Quality Control and any Two Methods of Quality Control. (May 2023 – 6 Marks)

Definition:

Quality Control (QC) is a software quality management activity used to examine and test the software product to identify defects and verify whether it meets specified quality requirements.

It focuses on detecting and correcting defects in the actual software product.

Objectives of Quality Control:

1. To identify defects in software.
2. To verify that software meets requirements.
3. To improve product quality.
4. To ensure software reliability.
5. To prevent defective products from reaching customers.

Methods of Quality Control:

### 1. Software Testing

Software Testing is a method of Quality Control in which software is executed with different inputs to identify defects and verify expected results.

Example: Testing an online banking application to verify whether money transfers work correctly and account balances are updated.

### 2. Software Inspection

Software Inspection is a formal technique in which software documents, source code and other work products are examined to identify defects without executing the software.

Example: Reviewing source code to identify incorrect logic, coding errors and violations of coding standards.

Other QC Activities:

- Reviews and walkthroughs.
- Functional testing.
- Performance testing.
- Defect tracking and reporting.

Advantages of Quality Control:

1. Identifies defects before product delivery.
2. Improves software reliability.
3. Ensures product quality.
4. Increases customer satisfaction.
5. Reduces the possibility of software failures.

Conclusion: Quality Control verifies the quality of the actual software product through testing, inspection and other defect-detection activities.
