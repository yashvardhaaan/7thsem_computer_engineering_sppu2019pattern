# 1. Limitations of Automation Testing



No Direct PYQ

Prepare for 4–6 Marks



## 1. What is Automation Testing?

Automation Testing is a software testing technique in which testing activities are performed automatically using tools and scripts instead of manually executing every test case.

Although automation improves speed and accuracy, it also has certain limitations.

## 2. Limitations of Automation Testing

1\. High Initial Cost

- Automation requires investment in tools, infrastructure and framework development.
- Some commercial automation tools have expensive licences.

2\. Requires Programming Knowledge

- Testers may need programming skills to create and maintain automation scripts.
- Learning automation frameworks requires time and training.

3\. Cannot Replace Manual Testing Completely

- Automation is not suitable for every testing activity.
- Exploratory testing, usability evaluation and testing based on human judgement often require manual testing.

4\. Script Maintenance

- Automation scripts must be updated whenever application functionality or user interfaces change.
- Frequent changes increase maintenance effort.

5\. Not Suitable for Frequently Changing Applications

- Applications under continuous development may require repeated modifications to automation scripts.
- This can reduce the benefits of automation.

6\. Limited Ability to Handle Unexpected Situations

- Automation scripts generally follow predefined instructions.
- They may not handle unexpected behaviour or complex situations without additional programming.

7\. Time-Consuming Initial Setup

- Developing automation frameworks and test scripts takes time.
- For small projects, manual testing may be faster and more economical.

8\. Tool Limitations

- Different tools support different platforms, browsers and technologies.
- A selected tool may not support every application requirement.

## 3. Example

Suppose a company develops an e-commerce website.

- Automated scripts can efficiently test login, registration and checkout repeatedly.
- However, evaluating whether the website's design is visually appealing or easy to use requires human judgement.
- If the login page layout changes, existing automation scripts may also need modification.

This demonstrates why automation cannot completely replace manual testing.

## 4. Conclusion

Automation Testing improves testing speed, accuracy and efficiency, but it has limitations such as high initial cost, programming requirements, script maintenance and limited human judgement. Therefore, combining manual and automation testing provides better testing coverage.
