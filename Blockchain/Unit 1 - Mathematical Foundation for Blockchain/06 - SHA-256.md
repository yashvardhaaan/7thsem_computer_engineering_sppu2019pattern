# 1. Introduction

Imagine you have written a document.

If someone changes **even one letter**, how can you detect it?

Instead of comparing the complete document, we calculate a **digital fingerprint**.

That fingerprint is called a **Hash**.

SHA-256 is the algorithm used to generate that fingerprint.

It is one of the most secure hashing algorithms and is extensively used in **Bitcoin, Blockchain, Digital Signatures, SSL/TLS, Password Storage, and File Integrity Verification.**

---

# 2. What is SHA-256?

**SHA-256 (Secure Hash Algorithm - 256)** is a cryptographic hash function developed by the **National Security Agency (NSA)** and standardized by **NIST**.

It belongs to the **SHA-2 family** of hash algorithms.

It converts **data of any size** into a **256-bit (32-byte)** fixed-length hash.

No matter how large the input is, the output is always **256 bits**.

---

# Why is it called SHA-256?

- **SHA** = Secure Hash Algorithm
- **256** = Produces a **256-bit hash**

Example

```
Input

Hello Blockchain

↓

SHA-256

↓

2CF24DBA5FB0A30E...
(256 bits)
```

---

# Important Characteristics

- Input can be any size.
- Output is always **256 bits**.
- One-way function.
- Deterministic.
- Collision resistant.
- Fast computation.
- Avalanche effect.

# 3. Working of SHA-256

Although the internal mathematics is complex, the overall process is easy to understand.

---

## Step 1 – Input Message

Original message is given as input.

Example

```
Blockchain Technology
```

↓

---

## Step 2 – Padding

Extra bits are added to the message.

Purpose:

- Make the message length compatible with the algorithm.
- Ensure the message length becomes **448 mod 512**.

Finally,

the original message length (64 bits) is appended.

Result:

```
Original Message

+

Padding Bits

+

Original Length
```

---

## Step 3 – Divide into 512-bit Blocks

The padded message is divided into blocks.

```text
Message

↓

Block 1 (512 bits)

↓

Block 2 (512 bits)

↓

Block 3...
```

Each block is processed independently.

---

## Step 4 – Initialize Hash Values

SHA-256 starts with **8 predefined 32-bit hash values**.

These are fixed constants defined by the SHA-256 standard.

```
H0

H1

H2

...

H7
```

These values change after processing every block.

> **Exam Tip:** You do **not** need to memorize the actual hexadecimal constants for SPPU exams.

---

## Step 5 – Compression Function

Each 512-bit block goes through **64 rounds of processing**.

Every round performs operations like:

- Bitwise AND
- XOR
- Right Rotation
- Addition modulo 2³²

These operations mix the data thoroughly.

```text
512-bit Block

↓

64 Rounds

↓

Updated Hash Values
```

---

## Step 6 – Final Hash

After all blocks are processed,

the final eight hash values are combined.

Result

```
256-bit Hash Value
```

Example

```
Message

↓

SHA-256

↓

185f8db32271fe25...
```

# Why Padding is Required?

Suppose the message length is

```
430 bits
```

SHA-256 processes data in

```
512-bit blocks
```

Padding fills the remaining space so that every block has the correct structure.

Without padding, the algorithm cannot process messages correctly.

# SHA-256 in Blockchain

SHA-256 is one of the core technologies behind Blockchain.

## 1. Block Hashing

Each block generates its own unique hash.

```text
Block

↓

SHA-256

↓

Block Hash
```

---

## 2. Linking Blocks

Every block stores the hash of the previous block.

```text
Block 1

↓

Hash

↓

Block 2

↓

Hash

↓

Block 3
```

If Block 1 changes,

its hash changes,

making all following blocks invalid.

---

## 3. Mining (Proof of Work)

Bitcoin miners repeatedly calculate SHA-256 hashes while changing the **nonce** until a valid hash satisfying the network difficulty is found.

```text
Block Data

+

Nonce

↓

SHA-256

↓

Valid Hash?

Yes → Block Accepted

No → Change Nonce
```

---

## 4. Data Integrity

SHA-256 immediately detects any modification in transaction or block data.

# Exam Answer (6 Marks)

## Explain the Working of SHA-256 Algorithm.

**Definition**

SHA-256 is a cryptographic hash algorithm that converts data of any size into a fixed 256-bit hash value.

**Working**

1. Accept the input message.
2. Add padding bits.
3. Append the original message length.
4. Divide the message into 512-bit blocks.
5. Initialize eight hash values.
6. Process each block through 64 compression rounds.
7. Combine the final hash values to generate the 256-bit output.

**Diagram**

```text
Input
  │
Padding
  │
Append Length
  │
512-bit Blocks
  │
64 Rounds
  │
256-bit Hash
```

# Interview Corner

### Why is SHA-256 used in Blockchain?

Because it provides a secure, fixed-length hash that detects tampering and links blocks together.

---

### Can SHA-256 be reversed?

No. It is a one-way hash function.

---

### Does SHA-256 encrypt data?

No.

It **hashes** data.

Encryption allows recovery of the original message using a key, whereas hashing does not.

---

### Why is SHA-256 preferred over MD5?

SHA-256 offers much stronger collision resistance and is considered secure for modern cryptographic applications.

---

# Key Points to Remember

- SHA = Secure Hash Algorithm.
- Produces a **256-bit** hash.
- Part of the **SHA-2 family**.
- One-way function.
- Uses **512-bit blocks**.
- Performs **64 compression rounds**.
- Used in Blockchain, Bitcoin, and Digital Signatures.
- Avalanche Effect ensures tiny input changes produce completely different hashes.
