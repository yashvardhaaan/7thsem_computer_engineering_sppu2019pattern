## **1. Introduction to Blockchain Types**

Blockchain networks are classified according to who can access the network, participate in transactions and validate blocks.

The three major types are:

- **Public Blockchain:** Anyone can participate.
- **Private Blockchain:** Only authorized participants can participate.
- **Consortium Blockchain:** A group of selected organizations manages the network.

## **2. Public Blockchain**

### **Definition**

A Public Blockchain is a decentralized and permissionless blockchain network in which anyone can join, read transactions, submit transactions and participate in the consensus process according to the network rules.

No central authority controls the entire network.

### **Architecture**

[defi-planet.com](https://defi-planet.com/2022/06/blockchain-101-the-different-types-of-blockchain-explained/?utm_source=chatgpt.com)

### **Working**

1. A user initiates a transaction.
2. The transaction is broadcast to the blockchain network.
3. Network nodes verify the transaction.
4. Miners or validators participate in consensus.
5. Valid transactions are grouped into a block.
6. The block is added to the blockchain.
7. The updated ledger is distributed across participating nodes.

### **Characteristics**

1. Open participation: Anyone can join.
2. Decentralization: No single organization controls the network.
3. Transparency: Transactions are publicly verifiable.
4. Security: Cryptography and consensus mechanisms protect the network.
5. Immutability: Confirmed records are difficult to modify.
6. Permissionless: No special authorization is generally required.

### **Advantages**

- High decentralization.
- Transparency and auditability.
- No central authority.
- Strong resistance to censorship.
- Global accessibility.

### **Disadvantages**

- Lower transaction throughput in many networks.
- Transaction fees may be high.
- Energy consumption can be high with Proof of Work.
- Transaction privacy is limited.
- Network scalability can be challenging.

### **Examples**

- Bitcoin.
- Ethereum.

## **3. Private Blockchain**

### **Definition**

A Private Blockchain is a permissioned blockchain network controlled by a single organization in which only authorized users can access, read, write or validate transactions.

It provides controlled access and greater privacy.

### **Architecture**

[vegavid.com](https://vegavid.com/blog/private-vs-consortium-blockchain-enterprise-governance?utm_source=chatgpt.com)

### **Working**

1. An organization establishes a blockchain network.
2. The administrator grants permission to selected users.
3. Authorized users initiate transactions.
4. Designated nodes verify transactions.
5. Consensus is achieved among authorized participants.
6. Valid transactions are added to the blockchain.
7. The updated ledger is shared with permitted participants.

### **Characteristics**

1. Permissioned access.
2. Controlled by a single organization.
3. Faster transaction processing in many implementations.
4. Greater privacy.
5. Limited participation.
6. Administrator controls user permissions.

### **Advantages**

- High transaction speed.
- Better access control.
- Greater data privacy.
- Lower resource consumption in many implementations.
- Suitable for internal organizational operations.

### **Disadvantages**

- Less decentralization.
- Dependence on a central administrator.
- Possibility of misuse by the controlling organization.
- Limited transparency.
- Requires trust in the organization.

### **Examples**

- Hyperledger Fabric.
- Private enterprise blockchain networks.

## **4. Consortium Blockchain**

### **Definition**

A Consortium Blockchain is a permissioned blockchain network managed by a group of selected organizations rather than a single organization.

Multiple organizations jointly control the network and participate in validating transactions.

### **Architecture**

[linkedin.com](https://www.linkedin.com/pulse/types-blockchain-part-4-series-roohi-bansal?utm_source=chatgpt.com)

### **Working**

1. Multiple organizations agree to establish a shared blockchain network.
2. Each organization operates authorized nodes.
3. Users initiate transactions.
4. Selected validator nodes verify transactions.
5. Participating organizations follow an agreed consensus mechanism.
6. Once consensus is achieved, the block is added.
7. All authorized organizations receive the updated ledger.

### **Characteristics**

1. Managed by multiple organizations.
2. Permissioned participation.
3. Shared decision-making.
4. Controlled access.
5. Improved collaboration.
6. Greater privacy than a fully public blockchain.

### **Advantages**

- No single organization has complete control.
- Shared responsibility.
- Better privacy and access management.
- Efficient transaction processing.
- Suitable for collaboration between organizations.

### **Disadvantages**

- Complex governance.
- Organizations must coordinate.
- Requires agreement among participants.
- Less decentralized than public blockchain.
- Disputes between members can affect operations.

### **Examples**

- R3 Corda (often used in multi-organization financial networks).
- Multi-bank consortium blockchain networks.

## **5. Difference Between Public, Private and Consortium Blockchain**

Important – Prepare for 8 Marks

| Basis            | Public          | Private             | Consortium             |
| ---------------- | --------------- | ------------------- | ---------------------- |
| Control          | Decentralized   | Single organization | Multiple organizations |
| Access           | Open            | Restricted          | Restricted             |
| Permission       | Permissionless  | Permissioned        | Permissioned           |
| Participants     | Anyone          | Authorized users    | Selected organizations |
| Transparency     | High            | Limited             | Shared among members   |
| Privacy          | Relatively low  | High                | High                   |
| Speed            | Generally lower | Generally higher    | Generally higher       |
| Decentralization | High            | Low                 | Partial                |
| Governance       | Network rules   | Single authority    | Joint governance       |
| Example          | Bitcoin         | Hyperledger Fabric  | R3 Corda               |
