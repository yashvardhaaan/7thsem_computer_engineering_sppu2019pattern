# **Unit III – Topic 4.1: Proof of Work (PoW)**

Direct PYQs in 4 papers

## **1. What is Proof of Work?**

**Proof of Work (PoW)** is a consensus mechanism in which miners compete to solve a complex mathematical puzzle by performing computational calculations. The first miner to find a valid solution gets the opportunity to add a new block to the blockchain and receive a reward.

PoW helps prevent fraudulent transactions and double spending by making block creation computationally expensive.

**Example:** Bitcoin uses Proof of Work to validate transactions and add new blocks.

## **2. How does Proof of Work work?**

[What is proof of work on Bitcoin? (Proof-of-work)](https://images.openai.com/static-rsc-4/ryYF5Isa-yKmbILVLFWH7am0FF3UW9jZ94DdUnZQ4Lfk_i2ME_VbdwY7SncOyinDvvxy-KYzuZ3JzfhvhkU4igh31-k5nXi-scjFEUjSDv0L4moV1yLTUbsNK7mgr3yYJExPL0GsH7CzcU7sqHle_JFqkoLx0uL9ksXYxUqAqSU?purpose=inline)

[bitstack-app.com](https://www.bitstack-app.com/en/learn-bitcoin/what-is-proof-of-work?utm_source=chatgpt.com)

1. **Transaction collection:** Users send transactions to the blockchain network.
2. **Block formation:** Miners collect valid transactions and form a candidate block.
3. **Puzzle solving:** Miners repeatedly change a value called the *nonce* and calculate the block hash.
4. **Target checking:** The calculated hash must be lower than the network's target value.
5. **Winner selection:** The first miner to find a valid hash broadcasts the block.
6. **Block verification:** Other nodes verify the block and its proof of work.
7. **Block addition:** If valid, the block is accepted into the blockchain.
8. **Reward:** The successful miner receives the block reward and transaction fees.

## **3. Important terms in PoW**

| Term          | Meaning                                                |
| ------------- | ------------------------------------------------------ |
| Miner         | Participant who performs mining calculations           |
| Nonce         | Number changed repeatedly to generate different hashes |
| Hash          | Fixed-length output generated by a hash function       |
| Difficulty    | Measure of how hard it is to find a valid hash         |
| Target        | Maximum hash value that qualifies as valid             |
| Mining reward | Reward given for successfully mining a block           |

**Important:** Bitcoin uses double SHA-256 hashing for its Proof of Work. Its target block interval is approximately 10 minutes, and mining difficulty adjusts every 2,016 blocks.

## **4. Example of Proof of Work**

Suppose the network requires a hash beginning with four zeros.

A miner tries different nonce values:

| Nonce | Generated hash (illustrative) | Result  |
| ----- | ----------------------------- | ------- |
| 100   | `8ab3...`                     | Invalid |
| 101   | `f72c...`                     | Invalid |
| 102   | `0000a...`                    | Valid   |

The miner finds a valid hash using nonce 102 and broadcasts the block to the network.

*This is a simplified illustration; Bitcoin actually compares the numerical hash value against a target.*

## **5. Advantages of PoW**

1. **High security:** Attacking the network requires enormous computational resources.
2. **Decentralisation:** Participants can compete to mine blocks without requiring prior approval.
3. **Double-spending protection:** Makes it expensive to rewrite transaction history.
4. **Transparency:** Transactions are publicly verifiable on public blockchains such as Bitcoin.
5. **Proven mechanism:** Bitcoin has used PoW since its launch.

## **6. Disadvantages of PoW**

1. **High energy consumption:** Mining requires substantial electricity.
2. **Expensive hardware:** Competitive mining often requires specialised equipment.
3. **Slow transactions:** Block creation and confirmation take time.
4. **51% attack risk:** An entity controlling most of the network's mining power may be able to reorganise recent transactions.
5. **Mining centralisation:** Large mining pools can concentrate mining power.

## **7. Applications / examples**

- **Bitcoin:** Uses PoW to secure its blockchain.
- **Litecoin:** Uses a PoW-based consensus mechanism.
- **Dogecoin:** Also uses PoW.

Note: Ethereum formerly used PoW but transitioned to PoS in September 2022.

# **Unit III – Topic 4.4: Proof of Activity**

## **1. What is Proof of Activity?**

**Proof of Activity (PoA)** is a hybrid blockchain consensus mechanism that combines features of **Proof of Work (PoW)** and **Proof of Stake (PoS)**.

In this mechanism, miners first perform computational work to create a candidate block. Then, a group of validators or stakeholders is selected to verify and approve the block.

It combines mining-based block creation with stake-based validation.

**Remember:** Proof of Activity here means the blockchain consensus algorithm, not Proof of Authority.

## **2. How does Proof of Activity work?**

[Proof-of-Activity (PoA): Definition & Erklärung](https://images.openai.com/static-rsc-4/KFiUtArpMtmi6VSImdWITunvyK8coeK8G1-FgptGChluGtZrLwIJV9kodWXe4Uqtha9SBaXpMvZQaGOxzqW7-rnDFQZSYxLCbbnW5N_YmXcAGpsDmLbb9u9EE7Md2OXfH261Ge2RK3BS1VmkXMWZ5GXtI0qmxB_8KjKU4EHImGA?purpose=inline)

[bitcoin-2go.de](https://bitcoin-2go.de/proof-of-activity/?utm_source=chatgpt.com)

1. **Transaction collection:** Transactions are collected from users and grouped into a candidate block.
2. **Mining:** Miners perform computational work, similar to PoW, to find a valid block header.
3. **Validator selection:** The network selects stakeholders or validators to participate in the next stage.
4. **Block verification:** Selected validators verify and approve the candidate block.
5. **Consensus:** The required validator approvals are collected.
6. **Block addition:** The completed block is added to the blockchain.
7. **Rewards:** Mining and validation participants receive rewards according to the protocol's rules.

## **3. Example**

Suppose miners create a candidate block by solving a PoW puzzle.

- Miner A successfully finds a valid block header.
- The network selects five stakeholders as validators.
- The validators check the block and approve it.
- Once the required approvals are received, the block is added to the blockchain.

Thus, PoW helps create the candidate block, while PoS-style participation helps validate it.

## **4. Advantages of Proof of Activity**

1. **Hybrid security:** Combines computational work with stake-based validation.
2. **Reduced dependence on mining alone:** Validators also participate in securing the network.
3. **Additional verification:** Stakeholders help verify proposed blocks.
4. **Economic incentives:** Participants have incentives to behave honestly.
5. **Security diversification:** An attacker may need to compromise more than one type of security mechanism.

## **5. Disadvantages of Proof of Activity**

1. **Energy consumption:** The PoW mining stage still consumes electricity.
2. **Complexity:** Combining two consensus approaches makes the protocol more complicated.
3. **Stake concentration:** Large stakeholders may gain greater influence.
4. **Implementation difficulty:** Validator selection and reward distribution require careful design.
5. **Scalability challenges:** Coordinating miners and validators can add overhead.

## **6. PoW vs PoS vs Proof of Activity**

| Feature        | PoW                                | PoS                  | Proof of Activity                   |
| -------------- | ---------------------------------- | -------------------- | ----------------------------------- |
| Main basis     | Computational work                 | Cryptocurrency stake | PoW + PoS-style validation          |
| Participants   | Miners                             | Validators           | Miners and validators               |
| Energy use     | High                               | Low                  | Depends partly on PoW mining        |
| Block creation | Mining puzzle                      | Validator selection  | Mining stage followed by validation |
| Complexity     | Relatively straightforward concept | Stake-based rules    | Hybrid mechanism                    |
