## **1. Introduction to Bitcoin**

Bitcoin is a decentralized digital cryptocurrency introduced in 2008 through a whitepaper published under the pseudonym Satoshi Nakamoto. Its network became operational in January 2009.

It allows users to transfer digital currency directly to one another without requiring a central authority such as a bank.

Bitcoin uses blockchain technology to maintain a distributed and transparent record of transactions.

**Definition for examination:**

Bitcoin is a decentralized peer-to-peer digital currency that operates on blockchain technology. It uses cryptographic techniques and a consensus mechanism called Proof of Work to validate transactions and maintain a secure distributed ledger without the involvement of a central authority.

## **2. Features of Bitcoin**

1. **Decentralization:** No central bank or government controls the Bitcoin network.
2. **Peer-to-peer:** Users can transfer Bitcoin directly to each other.
3. **Transparency:** Transactions are recorded on a publicly accessible blockchain.
4. **Security:** Cryptography protects transactions and ownership.
5. **Limited supply:** The maximum supply is 21 million Bitcoins.
6. **Pseudonymity:** Transactions use wallet addresses instead of directly displaying users' identities.
7. **Immutability:** Confirmed transactions are extremely difficult to alter.
8. **Global accessibility:** Bitcoin can be transferred across geographical boundaries.

## **4. Working of Bitcoin**

Bitcoin works through a decentralized peer-to-peer network.

### **Steps involved**

1. **Transaction creation:** Sender creates a transaction using their Bitcoin wallet.
2. **Digital signature:** The transaction is authorized using the sender's private key.
3. **Broadcasting:** Transaction is broadcast to the Bitcoin peer-to-peer network.
4. **Verification:** Nodes verify transaction validity, including signatures and spending conditions.
5. **Mining:** Miners select valid transactions and compete to solve a Proof of Work puzzle.
6. **Block creation:** A miner that finds a valid solution proposes a new block.
7. **Block verification:** Other nodes independently verify the block.
8. **Confirmation:** The accepted block becomes part of the blockchain.

## **5. Bitcoin Transactions**

A Bitcoin transaction transfers value between users.

Important elements:

- Input: References previously received, unspent Bitcoin.
- Output: Specifies where Bitcoin should be sent.
- Digital signature: Authorizes spending.
- Transaction ID: Identifies a transaction.
- Transaction fee: Incentivizes miners to include transactions.

Bitcoin uses the UTXO (Unspent Transaction Output) model to track spendable funds.

**Example:**

Suppose A wants to transfer 0.5 BTC to B.

1. A creates a transaction.
2. A authorizes it using the required private-key signature.
3. The network verifies the transaction.
4. A miner includes it in a block.
5. B receives the Bitcoin after the transaction is included in the blockchain.

## **6. Bitcoin Mining**

### **Definition**

Bitcoin mining is the process of verifying transactions, collecting them into blocks and adding valid blocks to the Bitcoin blockchain by solving a computationally difficult Proof of Work puzzle.

Miners use specialized hardware to perform calculations and compete to find a valid block hash.

### **Working of Bitcoin Mining**

1. **Transaction collection:** Miners collect unconfirmed transactions from the network.
2. **Block formation:** Selected transactions are arranged into a candidate block.
3. **Hash calculation:** Miners repeatedly calculate the block header hash using SHA-256 twice.
4. **Nonce adjustment:** Miners change the nonce and other permitted block-header data to generate different hashes.
5. **Target comparison:** The generated hash must be numerically less than or equal to the network's difficulty target.
6. **Block announcement:** The miner that finds a valid hash broadcasts the proposed block.
7. **Block verification:** Other nodes verify the Proof of Work and block validity.
8. **Block addition:** If valid, the block is accepted and added to the blockchain.

### **What is a Nonce?**

Nonce stands for *Number Used Once*.

It is a value that miners repeatedly change while attempting to find a hash that satisfies the network's difficulty target.

### **Mining Reward**

A successful miner can receive:

- Block subsidy: Newly issued Bitcoin according to the protocol.
- Transaction fees: Fees associated with transactions included in the block.

The block subsidy decreases through an event called Bitcoin halving.

## **7. Functionality of Miners**

This is particularly important because one of your uploaded papers directly asks about the functionality of miners.

Miners perform the following functions:

1. **Transaction verification:** Check transaction validity.
2. **Block formation:** Collect valid transactions into blocks.
3. **Proof of Work:** Perform computational calculations to find a valid hash.
4. **Double-spending prevention:** Help ensure that the same Bitcoin is not spent more than once.
5. **Blockchain maintenance:** Help extend the blockchain by proposing valid blocks.
6. **Network security:** Make attacks against the blockchain computationally expensive.
7. **Reward collection:** Receive block subsidy and transaction fees when successfully mining a block.

## **8. Advantages of Bitcoin**

- Decentralized payment system.
- No intermediary is required for peer-to-peer transfers.
- Globally accessible.
- Transparent transaction history.
- Strong cryptographic security.
- Limited supply.
- Resistant to censorship.

## **9. Disadvantages of Bitcoin**

- Price volatility.
- High energy consumption in Proof of Work mining.
- Transaction throughput limitations.
- Transaction fees can fluctuate.
- Transactions are generally irreversible.
- Regulatory uncertainty in different countries.
- Pseudonymous transactions can still be analysed and linked.
