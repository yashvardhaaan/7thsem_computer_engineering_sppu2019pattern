## **1. Introduction to Hyperledger**

Hyperledger is an open-source collaborative project hosted by the Linux Foundation. It was started in 2015 to develop enterprise-grade blockchain frameworks and tools.

It provides blockchain technologies that organizations can use to build secure, transparent and permissioned distributed ledger applications.

Hyperledger is not a cryptocurrency. It is an ecosystem of blockchain frameworks and tools.

### **Definition for examination**

Hyperledger is an open-source collaborative blockchain project hosted by the Linux Foundation that provides enterprise-grade frameworks and tools for developing permissioned distributed ledger applications. It enables organizations to build secure, scalable and transparent blockchain networks.

## **2. Features of Hyperledger**

1. **Permissioned network:** Only authorized participants can join the network.
2. **Privacy:** Transaction information can be restricted to authorized participants.
3. **Modular architecture:** Organizations can select components according to their requirements.
4. **Scalability:** Designed for enterprise applications with configurable network components.
5. **Security:** Uses cryptographic techniques for authentication and data protection.
6. **Smart contracts:** Supports business logic through smart contracts, called chaincode in Hyperledger Fabric.
7. **No mandatory cryptocurrency:** Hyperledger Fabric does not require a native cryptocurrency.
8. **Enterprise support:** Suitable for supply chains, banking, healthcare and business networks.

### **What is Chaincode?**

Chaincode is the smart contract code in Hyperledger Fabric that defines business rules and controls how participants interact with the ledger.

For example, in a supply chain application, chaincode can automatically verify product ownership and update shipment status when predefined conditions are satisfied.

## **5. Working of Hyperledger Fabric**

Hyperledger Fabric follows an Execute–Order–Validate transaction workflow.

[intellipaat.com](https://intellipaat.com/blog/tutorial/blockchain-tutorial/hyperledger-blockchain/?utm_source=chatgpt.com)

### **Steps involved**

1. **Transaction proposal:** A client application sends a transaction proposal to the required endorsing peers.
2. **Execution:** Endorsing peers execute the chaincode and simulate the transaction.
3. **Endorsement:** Peers return their signed endorsements and proposed read/write sets.
4. **Ordering:** The ordering service establishes the transaction order and packages transactions into blocks.
5. **Validation:** Peers check endorsement policies and transaction validity, including version conflicts.
6. **Commitment:** Valid transactions are committed to the ledger.
7. **Ledger update:** The updated blockchain and world state become available to the network participants.

**Important:** Unlike Bitcoin mining, Hyperledger Fabric does not require Proof of Work mining.

## **6. Important Components of Hyperledger Fabric**

### **6.1 Peer**

A peer is a node in the Hyperledger network that maintains a copy of the ledger.

Functions:

- Stores blockchain data.
- Executes chaincode when required.
- Validates transactions.
- Commits blocks to the ledger.

### **6.2 Ordering Service**

The ordering service:

- Receives endorsed transactions.
- Establishes their order.
- Groups transactions into blocks.
- Distributes blocks to peers.

### **6.3 Certificate Authority (CA)**

The Certificate Authority issues digital certificates to participants.

It helps establish identity and authenticate network members.

### **6.4 Ledger**

The ledger consists of two major parts:

1. **Blockchain:** Immutable sequence of transaction blocks.
2. **World State:** Current values of the data stored in the ledger.

### **6.5 Channels**

Channels allow selected organizations to maintain private transactions and separate ledgers within the same network.

### **6.6 Membership Service Provider (MSP)**

MSP manages identities and determines which participants are authorized to perform particular operations.

## **8. Advantages of Hyperledger**

- Provides controlled access.
- Maintains data privacy.
- Supports enterprise applications.
- Offers modular architecture.
- Does not require cryptocurrency.
- Supports smart contracts.
- Provides identity management.
- Allows multiple organizations to collaborate.

## **9. Disadvantages of Hyperledger**

- Requires authorized membership.
- Network setup can be complex.
- Governance requires coordination.
- Less decentralized than public blockchains.
- Requires technical expertise.
- Infrastructure and maintenance can be expensive.
