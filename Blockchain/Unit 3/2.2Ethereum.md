It allows developers to create decentralized applications and smart contracts that execute automatically according to predefined conditions.

### **Definition for examination**

Ethereum is an open-source, decentralized blockchain platform that enables developers to create and execute smart contracts and decentralized applications (DApps). It uses Ether (ETH) as its native cryptocurrency and Ethereum Virtual Machine (EVM) to execute smart contract code.

## **2. Features of Ethereum**

1. **Decentralization:** Ethereum operates through a distributed network of nodes without a central authority.
2. **Smart Contracts:** It supports self-executing programs that automatically perform predefined operations.
3. **Ether (ETH):** ETH is the native cryptocurrency used for transactions and network fees.
4. **Open Source:** Developers can access its code and build applications.
5. **Security:** Cryptographic techniques and consensus mechanisms protect the network.
6. **Transparency:** Transactions and smart contract interactions can be publicly verified.
7. **Decentralized Applications:** Supports DApps for finance, gaming, identity and other services.
8. **Programmability:** Developers can write smart contracts using programming languages such as Solidity.

### **3.1 Ethereum Accounts**

Ethereum has two main types of accounts.

**1. Externally Owned Account (EOA)**

- Controlled by a private key.
- Used by individuals to send transactions.
- Can hold ETH.
- Can interact with smart contracts.

Example: A user's Ethereum wallet.

**2. Contract Account**

- Controlled by smart contract code.
- Contains executable code and associated data.
- Executes when triggered by an appropriate transaction or contract interaction.
- Can hold ETH.

Example: A decentralized exchange smart contract.

## **4. Working of Ethereum**

Ethereum works through a decentralized network of nodes that process transactions and maintain a shared blockchain state.

### **Steps involved**

1. **Transaction creation:** A user creates a transaction using an Ethereum wallet.
2. **Digital signature:** The transaction is signed using the sender's private key.
3. **Broadcasting:** The transaction is broadcast to the Ethereum network.
4. **Validation:** Network nodes check the transaction's validity.
5. **Transaction execution:** The EVM executes the relevant operations, including smart contract code when applicable.
6. **Consensus:** Validators participate in Ethereum's Proof of Stake consensus process.
7. **Block inclusion:** Valid transactions are included in blocks.
8. **State update:** The blockchain state is updated and the transaction becomes part of the network's history.

## **5. Ether (ETH)**

Ether is the native cryptocurrency of the Ethereum blockchain.

### **Uses of Ether**

1. Payment for transaction fees.
2. Payment for smart contract execution.
3. Staking to participate in network security.
4. Transferring value between users.
5. Serving as an asset in decentralized finance applications.

**Example:**

Suppose A wants to send 2 ETH to B.

- A creates a transaction.
- A signs it using their private key.
- The transaction is broadcast to the network.
- Validators include the transaction in a block.
- B receives 2 ETH, subject to transaction validity and fees.

Ethereum Virtual Machine (EVM) is a decentralized execution environment that executes smart contract bytecode on the Ethereum network.

## **7. Gas Mechanism in Ethereum**

### **Definition**

Gas is a unit used to measure the computational effort required to execute operations and transactions on the Ethereum network.

Users pay transaction fees in ETH based on the gas consumed.

### **Why is Gas Required?**

- Prevents unnecessary computation.
- Compensates validators for processing transactions.
- Helps prevent infinite loops in smart contracts.
- Allocates network resources.
- Discourages spam transactions.

### **Working of Gas**

1. A user initiates a transaction.
2. The transaction specifies a gas limit and fee parameters.
3. The EVM executes the transaction.
4. Gas is consumed according to computational operations.
5. The user pays the applicable transaction fee.
6. Unused gas is not charged.

**Formula:**

\\[ \text{Transaction Fee}=\text{Gas Used}\times\text{Effective Gas Price} \\]

Example:

If a transaction consumes 21,000 gas and the effective gas price is 20 Gwei:

\\[ 21,000\times20=420,000\text{ Gwei} \\]

Transaction fee = 0.00042 ETH.

## **8. Ethereum Consensus Mechanism**

Ethereum currently uses Proof of Stake (PoS).

### **Working**

1. Validators deposit ETH as stake.
2. Validators participate in proposing and attesting to blocks.
3. The network follows its consensus rules to determine the canonical chain.
4. Honest validators receive rewards.
5. Validators who violate certain protocol rules can face penalties, including slashing.

## **9. Advantages of Ethereum**

1. Supports smart contracts.
2. Enables decentralized applications.
3. Provides an open development environment.
4. Eliminates many intermediaries.
5. Offers transparency and auditability.
6. Supports decentralized finance.
7. Provides a programmable blockchain platform.

## **10. Disadvantages of Ethereum**

1. Transaction fees can become expensive during congestion.
2. Network scalability remains a challenge.
3. Smart contract bugs can cause financial losses.
4. Transactions are generally irreversible.
5. Developers require blockchain-specific knowledge.
6. Public blockchain data provides limited transaction privacy.

## **11. Difference Between Bitcoin and Ethereum**

Important – 8 Marks

| Basis           | Bitcoin                        | Ethereum                                 |
| --------------- | ------------------------------ | ---------------------------------------- |
| Introduction    | 2009                           | 2015                                     |
| Founder         | Satoshi Nakamoto               | Vitalik Buterin and co-founders          |
| Primary purpose | Digital currency               | Smart contracts and DApps                |
| Cryptocurrency  | BTC                            | ETH                                      |
| Consensus       | Proof of Work                  | Proof of Stake                           |
| Programming     | Bitcoin Script                 | EVM-compatible smart contract languages  |
| Supply          | Maximum 21 million BTC         | No fixed maximum supply                  |
| Execution       | Primarily payment transactions | General-purpose smart contract execution |
| Block time      | Approximately 10 minutes       | Approximately 12 seconds per slot        |
| Applications    | Payments and store of value    | DeFi, NFTs, DApps and more               |

**Conclusion:** Bitcoin primarily focuses on decentralized digital money, whereas Ethereum provides a programmable blockchain platform for smart contracts and decentralized applications.
