# **Unit V – Blockchain Ethereum Platform Using Solidity**

## **Topic 2: Types of Ethereum Networks**

Ethereum networks are different environments in which users and developers can deploy smart contracts, perform transactions and test blockchain applications.

The three important network types in your syllabus are:

1. Ethereum Mainnet
2. Ethereum Testnet
3. Private Ethereum Network

### **1. Ethereum Mainnet**

**Ethereum Mainnet** is the primary, public Ethereum blockchain where real transactions and smart contracts operate.

**Features:**

- Public and permissionless network.
- Anyone can participate by running a compatible node.
- Uses real Ether (ETH).
- Transactions require actual gas fees.
- Smart contracts deployed here are available to network participants.
- Used for real-world decentralized applications.

**Example:** Deploying a production decentralized finance application on Ethereum Mainnet.

### **2. Ethereum Testnet**

**Ethereum Testnet** is a testing environment that behaves similarly to Mainnet but uses test Ether, which has no real monetary value.

**Features:**

- Used for testing smart contracts and DApps.
- Developers can experiment without spending real ETH.
- Helps identify errors before production deployment.
- Supports testing of transactions and application functionality.
- Test Ether is generally obtained through faucets.

**Example:** Testing a Solidity smart contract on the Sepolia test network before deploying it to Mainnet.

### **3. Private Ethereum Network**

A **Private Ethereum Network** is a blockchain network created for a specific organization or group. Access is restricted to authorized participants.

**Features:**

- Access is controlled by an organization.
- Only authorized users or nodes can participate.
- Used for internal business applications.
- Can provide greater control over permissions and data visibility.
- Network configuration and consensus rules can be customized.
- Can be used for enterprise testing and development.

**Example:** A company creates a private Ethereum network to manage internal supply-chain records among authorized departments and suppliers.

### **4. Comparison of Ethereum Mainnet, Testnet and Private Network**

| Basis            | Mainnet           | Testnet                        | Private Network                    |
| ---------------- | ----------------- | ------------------------------ | ---------------------------------- |
| Purpose          | Real transactions | Testing and development        | Organizational use                 |
| Access           | Public            | Public or community-accessible | Restricted                         |
| Currency         | Real ETH          | Test ETH                       | Depends on configuration           |
| Transaction cost | Real gas fees     | Test ETH gas                   | Depends on network setup           |
| Participants     | Anyone            | Developers and testers         | Authorized participants            |
| Data             | Public blockchain | Public testing blockchain      | Controlled by network participants |
| Usage            | Production DApps  | Testing smart contracts        | Enterprise applications            |

### **5. Advantages and limitations**

**Mainnet**

- Advantage: Real economic activity and public participation.
- Limitation: Real transaction fees and production risks.

**Testnet**

- Advantage: Safe environment for testing before deployment.
- Limitation: Testnet conditions may differ from Mainnet, and test assets have no real monetary value.

**Private Network**

- Advantage: Greater access control and customization.
- Limitation: Less decentralized and dependent on the organization operating it.
