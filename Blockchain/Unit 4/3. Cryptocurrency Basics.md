# **Unit IV – Cryptocurrency and Token**

## **Topic 3: Cryptocurrency Basics**

This topic covers the basic concepts behind cryptocurrency transactions and how users send, receive and secure digital currency.

### **1. Cryptocurrency transaction**

A cryptocurrency transaction is the transfer of digital currency from one wallet address to another through a blockchain network.

**Example:** A user sends 0.01 BTC to another user's Bitcoin address.

### **2. Public key and private key**

| Public key                                     | Private key                       |
| ---------------------------------------------- | --------------------------------- |
| Used to derive a wallet address.               | Used to authorize transactions.   |
| Can be shared publicly.                        | Must be kept secret.              |
| Helps others send funds to you.                | Proves control over the funds.    |
| Does not provide spending authority by itself. | Must never be shared with others. |

### **3. Cryptocurrency wallet address**

- A wallet address is an identifier used to receive cryptocurrency.
- It is generally derived from public-key information.
- Different cryptocurrencies use different address formats.
- Always verify the network and address before sending funds.

1. **Initiation:** The sender enters the receiver's wallet address and the amount.
2. **Signing:** The sender authorizes the transaction using their private key.
3. **Broadcasting:** The transaction is shared with the cryptocurrency network.
4. **Validation:** Network nodes check the transaction's validity, including whether the sender has sufficient funds.
5. **Confirmation:** The transaction is included in a block through the network's consensus mechanism.
6. **Recording:** The block is added to the blockchain, and the receiver's balance is updated.

### **5. Role of cryptography**

Cryptography helps protect cryptocurrency transactions.

- **Hashing:** Converts input data into a fixed-length output. It helps maintain blockchain data integrity.
- **Digital signatures:** Verify that a transaction was authorized by the holder of the relevant private key.
- **Public-key cryptography:** Uses related public and private keys for secure transaction authorization.
- **Encryption:** Protects information where encryption is used; public blockchain transaction data is not necessarily private or encrypted.

### **6. What is a cryptocurrency token?**

A **token** is a digital asset created and managed on an existing blockchain platform. It can represent different forms of value, rights or utility.

Examples:

- Utility token – provides access to a product or service.
- Security token – represents an investment or financial interest.
- Governance token – gives holders voting rights in a project.
- Stablecoin – aims to maintain a stable value relative to an asset or currency.

**Difference between coin and token:**

| Coin                                    | Token                                                  |
| --------------------------------------- | ------------------------------------------------------ |
| Has its own native blockchain.          | Usually operates on an existing blockchain.            |
| Used for network transactions and fees. | May represent utility, ownership, governance or value. |
| Example: Bitcoin (BTC), Ether (ETH).    | Example: USDC on Ethereum.                             |
